## 一、Demo 目标与叙事

**核心演示：** 贡献记录 → x402 证明 → Cobo Agentic Wallet 自动收益分配

**这是 A2A Economy / Agent-Native Payments 的真实演示：AI Agent 自己持有钱包、自己发起分配。**

不要求功能完整，不要求 UI 美观——**要求闭环跑通，能录屏/截图证明**。

---

## 二、技术栈（暂定，可优化）

| 模块 | 技术 |
|------|------|
| 链侧 | Hardhat + Polygon Mumbai |
| 合约 | Solidity（分配合约 + x402 接口） |
| 前端 | Next.js + TypeScript + wagmi |
| 钱包 | Cobo Agentic Wallet SDK |
| 证明 | x402 协议 |
| Agent | 贡献记录 + 证明生成 + 调度逻辑 |

**不强制接入 GLM-5.1**，视情况需要再定。
