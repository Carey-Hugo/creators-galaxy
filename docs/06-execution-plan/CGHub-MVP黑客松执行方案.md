## 一、MVP目标：演示什么

### 核心演示：贡献到收益的完整闭环

```
步骤1：用户创建一个项目，设置分配规则（智能合约）
步骤2：项目成员提交贡献
步骤3：CGHub Agent记录贡献（自动）
步骤4：x402协议生成可验证的贡献证明
步骤5：智能合约按规则自动分配收益（钱包到账）
```

**这是"贡献记录 → Agent处理 → x402证明 → 链上分配"的最小闭环演示。**

不要求功能完整，不要求界面精美——**要求闭环跑通，能截图/录屏证明**。

## 三、分阶段计划

### Day 1-2（6/1-6/2）：搭框架，定合同

**目标：** 合约骨架出来，前端基础框架搭建

| 任务 | 负责人 | 交付 |
|------|--------|------|
| 设计分配合约逻辑（谁贡献多少，按比例分配） | Solidity | 合约草稿 |
| 前端项目初始化（Next.js） | 前端 | 可运行页面 |
| 确定MVP功能列表（不超过5个） | 统筹 | 功能清单 |

**合约核心逻辑：**
```
- 创建项目 + 设置分配比例（如：甲40%，乙30%，丙30%）
- 项目管理员提交成员贡献记录
- 调用合约，按比例从项目池子转USDC到各成员钱包
```
