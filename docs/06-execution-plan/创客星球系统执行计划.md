## 十、风险与应对

```
【风险1：冷启动没人来】
应对：
→ 邀请制核心群（20-30人先动起来）
→ 公众号内容驱动（文章要好）
→ 个人品牌背书（创始人是活广告）

【风险2：内容更新难以持续】
应对：
→ 建立内容模板（SOP）
→ 我帮你提供初稿（每周1篇）
→ 批量准备（提前写好3-5篇）

【风险3：网站开发超预算/超时间】
应对：
→ 先用WordPress/Discourse（最便宜最快）
→ MVP只做核心功能
→ 后期随收入增长再迭代

【风险4：小报童没人买】
应对：
→ 先免费积累500+公众号读者
→ 首批优惠价¥66（不高）
→ 内容要足够好（值得付费）

【风险5：探路者来了但留不住】
应对：
→ 社区运营要跟上（不能只靠工具）
→ 核心群要有温度（不是冷冰冰的论坛）
→ 持续输出（每周内容/每月活动）
```
