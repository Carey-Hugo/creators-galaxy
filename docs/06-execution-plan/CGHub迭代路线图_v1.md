## 🏗️ v1.0（MVP）— 2026 Q2-Q3

### 目标
> 验证"创客需要链上价值记录"这一核心假设

### 核心功能

| 功能 | 优先级 | 说明 |
|------|--------|------|
| Web3 身份注册 | P0 | 钱包登录，自动生成主页 |
| 个人主页/作品集 | P0 | 展示创客信息+作品 |
| 简单项目发起 | P0 | 创建项目+设置分配比例 |
| 贡献记录（手动） | P0 | 项目内记录成员贡献 |
| 收益分配（手动触发） | P0 | 按比例链上分配 |
| AI 助手基础版 | P1 | 问答+数据查询 |

### 技术选型

```
前端：Next.js + TypeScript + wagmi
后端：Node.js + PostgreSQL（中心化部分）
链上：Polygon（低Gas，生态成熟）
钱包：MetaMask + Safe（多签支持）
合约：Hardhat（开发） + OpenZeppelin（安全）
```

### 交付物
- [ ] 可运行的 Web 应用（Alpha版本）
- [ ] 3-5个内测创客用户
- [ ] 至少1个真实项目跑通全流程

### 验证指标（KPI）
```
① 创客注册转化率（访问→注册 > 30%）
② 项目创建完成率（发起→部署 > 50%）
③ 用户次周留存（ > 40%）
④ 分配操作成功率（ > 90%）
```

## 📈 v2.0（增长）— 2026 Q4

### 目标
> 接入去中心化社交图谱，实现裂变增长

### 核心功能

| 功能 | 优先级 | 说明 |
|------|--------|------|
| Lens Protocol 集成 | P0 | Web3 社交登录+内容同步 |
| 创客主页 Lens 化 | P0 | 个人主页 = Lens Profile |
| 内容发布（Web3原生） | P0 | 文章/代码直接发布到 Lens |
| 社交图谱发现 | P0 | 基于 Lens 关系推荐 |
| OPC 合伙人机制 | P1 | 加入即记录贡献，类空投 |
| AI Agent 增强 | P1 | 自然语言创建项目+合约 |
| 订阅/打赏功能 | P2 | 粉丝经济（USDC） |

### 技术选型

```
新增集成：
- Lens Protocol SDK
- CyberConnect（社交图谱）
-erc20（订阅代币）

升级：
- 合约：引入 Lens 治理模块
- 前端：增加社交Feed流
```

### 交付物
- [ ] Lens 生态官方集成
- [ ] 100+ 活跃创客
- [ ] 10+ 真实协作项目

### 验证指标
```
① Lens Profile 绑定率 > 60%
② 月活创客 > 100
③ 项目成功率 > 70%
④ 用户推荐率（K因子）> 1.2
```

## 🌐 v3.0（生态）— 2027 Q1-Q2

### 目标
> 开放平台，第三方开发者可构建插件

### 核心功能

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 开放API/SDK | P0 | 第三方可接入CGHub数据 |
| 插件市场 | P0 | 第三方开发工具上架 |
| 开发者激励 | P0 | API调用费分成 |
| 多链支持 | P1 | Ethereum + Solana + 更多 |
| 跨平台身份 | P1 | 连接 Web2 账号（GitHub/Twitter） |
| 企业版白标 | P2 | 企业定制化部署 |

### 技术选型

```
新增：
- Graph Protocol（去中心化数据查询）
- IPFS/Filecoin（去中心化存储）
- DID（去中心化身份）

架构升级：
- 微服务化
- 合约平台化（可升级合约）
```

### 交付物
- [ ] 开放API文档
- [ ] 10+ 第三方插件
- [ ] 5+ 企业客户
- [ ] 1000+ 月活创客

### 验证指标
```
① API 调用量 > 10万/月
② 第三方插件数 > 10
③ 企业客户收入占比 > 20%
④ 月活创客 > 1000
```

## 🔥 v0（黑客松版）— 紧急插队

### 定位
> Hackathon 路演专用，快速搭建可演示版本

### 最简技术栈

```
前端：Next.js（手动生成页面，不接后端）
后端：无（数据写死在页面）
链上：Polygon Mumbai 测试网（模拟）
合约：Hardhat（本地部署+公开ABI）

演示方案：
- 手机截图演示钱包连接
- 预录视频演示完整流程
- Etherscan展示已部署合约
```

### 时间分配
```
Day1：搭建基础框架（2小时）
Day2：完成合约+前端对接（3小时）
Day3：调试+演示+预录（2小时）
Day4：路演（随时待命）
```
