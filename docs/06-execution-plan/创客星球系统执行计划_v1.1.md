## 一、时间资源模型

### 1.1 每日可用时间

```
每天可用时间：3-4小时
上限：5小时（不超）

时间块划分：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
上午块（可选）：30分钟-1小时
→ 处理紧急消息、回复评论、刷数据

下午块（主创作）：1.5-2小时
→ 公众号文章 or 书籍章节 or 小报童内容

晚间块（辅助）：1-1.5小时
→ 社区互动、产品规划、白皮书、其他

休息日：每周至少1天完全休息
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 1.2 并行创作原则

```
【旧模式】书籍完成 → 小报童上线 → 公众号连载
【新模式】三线并行，互相滋养

公众号文章 ←→ 书籍章节
    ↓              ↓
小报童内容   白皮书素材
    ↓              ↓
三方同步优化（同一素材，多个出口）
```

**具体做法：**
- 写公众号时，同步积累书籍素材
- 书籍章节中的精华观点 → 提炼 → 小报童深度内容
- 任何场景下发现的好案例/数据 → 同步到白皮书素材库
- 书籍、小报童、白皮书不是三个独立项目，是同一棵树的三根枝

## 三、主线A：内容产品（三线并行）

### 3.1 创作日历模板（每周）

```
周一：公众号文章（主创作1.5-2小时）
周二：书籍章节 or 小报童内容（1.5-2小时）
周三：公众号文章（主创作1.5-2小时）
周四：白皮书内容 or 平台规划（1-1.5小时）
周五：公众号文章 or 书籍章节（1.5-2小时）
周六：弹性（可选1-2小时，或完全休息）
周日：完全休息 or 轻量内容（30分钟-1小时）
```

**节奏原则：**
- 每周至少2篇公众号
- 争取第3篇（多出的时间是超额完成）
- 书籍和小报童按章节推进，不追求每天都有可见产出
- 白皮书素材在日常积累，不单独花整块时间

### 3.2 公众号连载计划

```
【目标】
→ 每周2-3篇，每篇1500-2500字
→ 干货为主，有观点，有温度
→ 所有平台统一署名"Carey Hugo"

【内容来源】
→ 书籍章节的精华提炼
→ 实时案例分析（AI时代新动态）
→ 个人故事和心路历程
→ 读者问题解答（收集评论区问题）

【文章模板】
→ 标题：引发好奇，承诺价值
→ 开头：直接抛问题/现象（300字内）
→ 中段：案例+分析（1000-1500字）
→ 结尾：引发思考 or 号召行动（200-300字）
→ 引导：文末带"上船"CTA

【发布节奏】
→ 周一：必发（核心文章）
→ 周三：必发（第二篇）
→ 周五 or 周六：可选第三篇（超额完成）
→ 周末：可发短内容（500-800字）
```

### 3.3 书籍创作计划

```
【当前状态】
→ 大纲已完成（13章完整结构）
→ 尚未开始正式写作
→ 这是最大待办项

【写作方式】
→ 按章节推进，每章 = 3000-5000字
→ 章节内部分段写，不追求一气呵成
→ 每天写一点，积累式完成

【并行策略】
→ 公众号文章的深度版 → 书籍对应章节
→ 书籍章节的精华 → 提炼 → 公众号短文
→ 两者互相滋养，不是重复劳动

【目标】
→ 第1-3个月：完成全部13章初稿
→ 第4-6个月：编辑校对 + 优化
→ 第7-9个月：申请ISBN + 版面设计
→ 第10-12个月：电子书上线 + 纸质书出版
```

### 3.4 小报童产品计划

```
【上线时间】第3个月

【产品形态】
→ 书籍完整电子版（13章）
→ 每章配深度解读（额外500-1000字）
→ 白皮书预告（抢先看）
→ 专属读者群（微信群）
→ 早期探路者专属福利

【定价】
→ 早期优惠价：¥66/年（首批探路者）
→ 正式定价：¥99/年

【并行策略】
→ 不等书籍写完再启动小报童
→ 第1个月就开始积累小报童内容
→ 书籍初稿完成 → 小报童立即上线
→ 公众号连载同步进行 → 为小报童引流

【发布节奏】
→ 第1-2个月：打磨内容，但不发布
→ 第3个月：小报童正式上线
→ 第4个月起：持续更新，每完成1章同步1章
```

### 3.5 白皮书内容积累

```
【定位】
→ 商业白皮书：完整讲述CGHub生态系统
→ 技术白皮书：讲述技术架构和DAO治理
→ 不是单独项目，是所有内容的顶层提炼

【日常积累原则】
→ 不单独花整块时间写白皮书
→ 在写公众号、书籍、社区文档时
→ 发现适合白皮书的素材 → 随手标记
→ 定期（每周30分钟）整理素材库

【素材标注格式】（在笔记里随手记）
→ [白皮书-商业] 案例：xxx
→ [白皮书-技术] 机制：xxx
→ [白皮书-叙事] 金句：xxx
```
