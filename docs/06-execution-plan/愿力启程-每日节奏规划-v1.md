> 状态：✅ 胡哥确认（2026-07-14）
> 性质：**活文档** —— 每周六复盘时更新，git 存档
> 核心原则：**6天工作制 + 周日完全放松 + 周六晚上复盘**。不赶、不累、不匆忙。

## 〇、总纲

**一条主线**：愿力启程课程体系（咨询→课程→智慧教练/高阶）
**两个战场**：
- **横向**（上午）= 思想体系·智力智库 → 不限地域的知识资产
- **纵向**（下午）= 本地社区联动·实践 → 愿力实践落地 + 现金流

**循环迭代机制**：
- 每日骨架：上午横 / 下午纵 / 晚上补
- 每周六晚：复盘 + 深度思考 + 更新本文档
- 每30天：现金流 / 产品 / IP 三维度检查

## 三、个人IP · 跑步口播

- **身份**：跑友/跑者（运动健康人设）
- **场景**：跑步后户外录制口播（解决书房背景未布置问题）
- **形式**：口播真人出镜 + 原视频流水线（自动化）结合，来不及时用流水线
- **节奏**：不是每天跑；不跑的日子陪家人/补工作
- **素材流**：晚上跑步录 → 来不及剪辑 → 第二天上午完成

## 四、产品线（一体的漏斗）

```
咨询（入口·定制）→ 课程（交付）→ 智慧教练/高阶（深度）
        ↓ 打包推广
   星球/社区（沉淀）
```

- **咨询**：个性化定制，尊重客户时间；优先上午，但不锁死（上午/下午/晚上看客户）
- **课程**：引流课19.9 → 系统课199/299 → 高阶（愿力领导力）
- **推广逻辑**：咨询本身也是为智慧教练 + 课程打包做推广——**一体化的**
