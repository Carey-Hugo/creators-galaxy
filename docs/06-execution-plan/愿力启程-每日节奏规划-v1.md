## 〇、总纲

**一条主线**：愿力启程课程体系（咨询→课程→智慧教练/高阶）
**两个战场**：
- **横向**（上午）= 思想体系·智力智库 → 不限地域的知识资产
- **纵向**（下午）= 本地社区联动·实践 → 愿力实践落地 + 现金流

**循环迭代机制**：
- 每日骨架：上午横 / 下午纵 / 晚上补
- 每周六晚：复盘 + 深度思考 + 更新本文档
- 每30天：现金流 / 产品 / IP 三维度检查

## 二、每周节奏（6天工作制 + 1天放空）

### 内容发布日历

| 星期 | 内容 | 发布时点 |
|:--|:--|:--|
| **周一** | **创作图文**（为周二准备） | 不发布 |
| **周二** | **图文定时发布** + 短视频创作 | 5:55定时 + 当天发 |
| **周三** | **创作图文**（为周四准备） | 短视频可补（来不及顺延） |
| **周四** | **图文定时发布** + 短视频创作 | 5:55定时 + 当天发 |
| **周五** | **创作图文**（为周六准备） | 短视频可补（来不及顺延） |
| **周六** | **图文定时发布** + 短视频创作 + **晚上复盘** | 5:55定时 + 当天发 + 晚间复盘 |
| **周日** | **完全放松·随心情** | 发生活类/观点类/家庭内容，不做要求 |

### 发布规则
- **图文（书籍连载）**：**周二、周四、周六** 5:55 定时发布；创作在前一天（1/3/5）完成，从容不赶
- **短视频**：**周二、周四、周六** 当天做完当天发；来不及就顺延 **3/5/7**；周日发生活类
- **定时发布不占创作时间**：图文 5:55 已自动发出，上午空出来做短视频/咨询

### 内容频率对比（原 → 新）

| 内容 | 原来 | 现在 |
|:--|:--|:--|
| 书籍连载 | 周三、周六 | **周二、周四、周六**（5:55定时，1/3/5创作） |
| 短视频 | 低频 | **周二、周四、周六**（可延3/5/7） |

### 周日 · 完全放松（无计划）
- 不做任何强制要求，随心情
- 核心目的：**发散思维 → 找灵感、找方向、定方向、校准方向**
- 可发一点**有血有肉的内容**：生活类、观点类、家庭生活都可以
- **IP 不是全发干货**——生活化内容让人看到真实的你，IP 才有血有肉

## 三、个人IP · 跑步口播

- **身份**：跑友/跑者（运动健康人设）
- **场景**：跑步后户外录制口播（解决书房背景未布置问题）
- **形式**：口播真人出镜 + 原视频流水线（自动化）结合，来不及时用流水线
- **节奏**：不是每天跑；不跑的日子陪家人/补工作
- **素材流**：晚上跑步录 → 来不及剪辑 → 第二天上午完成
