## 四、7天大纲

### 整体逻辑线

```
Day1-2  向内看  → 你在哪个层次？你的愿力纯度几何？
Day3-4  向外看  → 不是你的问题，是这个时代。新规则是什么？
Day5-6  向前走  → 有路、有人、有方法。设计你的第一步。
Day7    向上跃  → 这不是结束，是入口。
```

---

### Day 1 · 四个词，你分得清吗？

**核心钩子**：大部分人一辈子都在追愿望，却从没触到过愿力。

| 模块 | 内容 |
|:--|:--|
| 痛点开场 | "你是不是也这样——每次换方向都觉得自己找到了'真正想做的事'，但三个月后又在看新机会？" |
| 概念拆解 | 愿望 ≠ 梦想 ≠ 使命 ≠ 愿力。四层金字塔，大多数人在第一层打转。 |
| 认知升级 | 愿望是"我想要"，愿力是"我愿意"。一个是消费心态，一个是创造心态。 |
| 课后练习 | 写出你过去三年换过的三个方向，判断每次驱动你的是哪一个词。 |
| 留钩子 | "明天教你三个标志，测你到底离愿力还有多远。" |

---

### Day 2 · 3个标志，测你的愿力纯度

**核心钩子**：如果你对一件事做不到"可承诺、可承受、可生长"，那不是愿力。

| 模块 | 内容 |
|:--|:--|
| 引入 | 昨天你写下的三个方向——为什么都走不远？因为缺了一个关键东西。 |
| 方法论 | 愿力三标：① 可承诺（没人看你也做）② 可承受（代价你能扛）③ 可生长（不是循环，是螺旋上升） |
| 自测工具 | 给你的三个方向打分，看哪个接近愿力 |
| 课后练习 | 用三标给现在在做的事打分，诚实回答"它值得一辈子吗？" |
| 留钩子 | "如果你的分数不高——别自责。明天我告诉你，问题不在你身上。" |

---

### Day 3 · 为什么你"想明白却活不出来"

**核心钩子**🔥：不是你不行，是这个时代正在批量制造"清醒却无力"的人。

| 模块 | 内容 |
|:--|:--|
| 共鸣延续 | 前两天的自我诊断结果——很多人会发现"没有一项及格"，然后陷入自我怀疑。停下来。 |
| 框架破局 | **马克思主义分析视角**：AI替代的不是工作，是"个人努力→回报"的因果链。生产关系变了，你还在用旧规则玩。 |
| 案例 | 为什么十年前"努力就有好日子"到今天不管用了？举例：翻译、设计、编程——不是你不努力，是努力的红利被抽走了。 |
| 核心观点 | "想明白却活不出来"不是意志力问题，是你在旧生产关系里跑新赛道。 |
| 留钩子 | "明天我们继续挖——这个时代到底在发生什么。" |

---

### Day 4 · AI时代，个人何去何从

**核心钩子**🔑：当"个人奋斗"失效，你不该更努力，你该换赛道。

| 模块 | 内容 |
|:--|:--|
| 深化框架 | 接 Day 3——不是贩卖焦虑，是直面真相。AI 时代的三重变化：工作→任务化、组织→社区化、价值→贡献化。 |
| 对照表 | 旧时代：学历→工作→积累→退休。新时代：愿力→实践→协作→持续生长。 |
| 转折点 | "这就是为什么你需要愿力。不是鸡汤，是新时代唯一的导航系统。" |
| 课后练习 | 你现在的赚钱方式属于"旧时代"还是"新时代"？列出来。 |
| 留钩子 | "空谈没意思。明天开始我给你看——真的有人在用新规则活了。" |

---

### Day 5 · 有人已经在走了

**核心钩子**：原来不是没有路，是你没看见路在哪。

| 模块 | 内容 |
|:--|:--|
| 世界观 | **Web3经济机制**简介：贡献即资产、实践即确权——不是公司发工资，是社区回报你的真实贡献。 |
| 案例 | **益邻家园**实践：「贡献有回报」理念在运转的真实社区。徐泾社区居民自组织、协作记录、价值回流——不是概念，是正在发生的事。 |
| 核心公式 | 愿力 × 社区协作 × 价值回流 = 新时代的生存方式 |
| 课后练习 | 你做的事情中，有哪件如果放在一个"贡献有回报"的社区里，可能会被放大？ |
| 留钩子 | "明天，我们来设计你自己能落地的第一步。" |

> 📌 注：不提"CGHub/创客星球"品牌名，用益邻家园实践事实作为案例。品牌名待正式重启后挂回。

### Day 6 · 你的最小实践

**核心钩子**：不要等"准备好"，先做一件小到你不会失败的事。

| 模块 | 内容 |
|:--|:--|
| 方法论 | "最小实践"原则：不是辞职、不是裸奔、不是投钱。是在你现有的生活里，放一颗愿力的种子。 |
| 案例 | 一个学员：每周写一篇"我今天做了什么值得记录的事"——三个月后，他在社区里被人认出来了。 |
| 课后练习 | 设计你的最小实践：① 什么事你愿意做一年不求回报？② 每周只需 30 分钟 ③ 做完在哪里分享？ |
| 留钩子 | "明天结课，但这不是结束——我要给你看一个更大的东西。" |

### Day 7 · 启程 + 彩蛋（直播结课）

**核心钩子**：你刚刚经历的 7 天，不是一门课，是一个入口。

| 模块 | 内容 |
|:--|:--|
| 复盘 | 回顾 7 天：从四个词分不清 → 到能判断自己的愿力纯度 → 到看见时代真相 → 到设计了最小实践。你不是原来的你了。 |
| 课程衔接 | "做了最小实践之后怎么持续？怎么和同路人一起？怎么让实践真的产生回报？" → 这就是第2站·愿力实战要解决的。 |
| 🎁 彩蛋 | 揭晓 Hugo 本人的秘密："愿力定方向 + AI 给能力"——7 天的课程内容，是 Hugo 自己走出来的路。而 Hermes AI 助手，就是把"愿力+AI"活成案例的证据。 |
| CTA · 主推动 | "系统课限时通道现在开放。直播结束前报名，锁定199名额。"（全程不提次日） |
| CTA · 收尾 | **仅在结课最后时刻追加一句**："考虑到有些朋友可能还没想清楚、或者刚进来来不及——给大家一个最后期限，明天晚上 24:00 之前，通道还在。过了明天这个点，恢复 299。" 这不是催促，是一份人情。让大家感觉到不是冷冰冰的商业行为，而是我们在照顾每一个人的节奏。 |

## 五、直播 CTA 策略

| 阶段 | 话术策略 | 心理机制 |
|:--|:--|:--|
| **直播全程** | 只制造紧迫感："现在报名，锁定199" | 情绪高点，80% 在此转化 |
| **结课收尾时** | 追加一份人情："明天 24:00 前还有通道" | 照顾犹豫者，让大家感受到不是冷冰冰的商业，是我们在照顾每个人的节奏 |

> ⚠️ 全程不提"明天 24:00"。只在最后收尾时说一次。让 80% 在兴奋点完成报名，剩余 20% 感受到一份人情。
