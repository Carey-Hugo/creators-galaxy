- 引流课学员报系统课后看到的全是新内容，没有重叠

## 五、一源多用流程

```
创作一个内容时，同时产出多种格式：

                    ┌── 系统课完整版（45min逐字稿+课件）
                    │
     原始主题 ──────┼── 引流课精华版（10min逐字稿+课件）
                    │
                    ├── 连载深度篇（2000-3000字公众号）
                    │
                    └── 短视频脚本（1-2min）
                    
原则：先做深度再做精简
      先写系统课完整内容→提取引流课精华→提取短视频
      连载可独立创作也可以从课程内容反推
```
