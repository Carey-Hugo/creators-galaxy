## 二、品牌架构体系方案

### 品牌层级关系

```
MoWa 愿力文明
│  底牌哲学 / 世界观 / 愿力理论
│  定位：后端体系，不直接面向学员营销
│  视觉：深邃、宏大、宇宙感
│
├── 益邻家园 ELINK
│  社区实践层 / 使用场景 / 共建载体
│  定位：独立品牌，面向社区成员
│  视觉：已定稿（深蓝+紫晶+暖金+月白+嫩绿）
│  Logo：中心嫩芽-水晶 + 外围人形守护圈
│
├── 愿力启程
│  ★ 教育转化层 / 课程产品 / 学员入口
│  定位：独立产品线，面向三类目标人群
│  视觉：待设计（需与ELINK呼应，但不同）
│  Logo：待设计
│
└── 愿力星门 / 生命品牌
    高阶咨询层 / 深度服务 / 高客单价
    定位：未来引入，先预留视觉空间
```

### 各层级视觉连接策略

```
              MoWa（底牌）
              ┌──────┐
              │ 深色底 │──── 共享 ──→ 所有子品牌都用深色基调
              │ 金色光 │──── 共享 ──→ 金色作为串联色
              └──────┘
              │
    ┌─────────┼────────────┐
    ▼         ▼            ▼
  ELINK    愿力启程     愿力星门(未来)
  (紫为主)  (金为主)    (透明/光效为主)

  ═══════════════════════════════
  共同 DNA（3个品牌必须共享）：
  ┌────────────────────────────┐
  │ ① 深蓝色系（#1A2347）       │
  │ ② 金色点缀（#F4D06F）      │
  │ ③ 光的质感（发光的元素）    │
  │ ④ 极简现代感               │
  └────────────────────────────┘
  
  差异化（每个品牌突出不同主色）：
  ┌────────────────────────────┐
  │ ELINK        → 紫水晶      │
  │ 愿力启程     → 暖金 + 曙光 │
  │ 愿力星门     → 透明/光晕   │
  └────────────────────────────┘
```

## 五、补充说明：为什么要系统做品牌

| 理由 | 说明 |
|:--|:--|
| **转化信任** | 学员看到专业Logo+统一视觉，信任度提升30%+ |
| **社群沉淀** | 统一品牌方便后期学员自发传播和识别 |
| **定价支撑** | 引流课19.9 → 系统课199 → 星门高价咨询，每层都需要视觉升级支撑定价 |
| **MoWa一致性** | 未来引入愿力星门/生命品牌时，用户会觉得"这是同一套体系"，不是临时拼凑 |
| **效率提升** | 锁定风格后，后续所有课件/封面/海报只需套模板，不再每次重新设计 |
