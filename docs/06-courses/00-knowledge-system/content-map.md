# 系统课「愿力实战营」内容地图

> **定位**：愿力实战营（对外名）——引流学员专享 **199** / 非学员活动价 **399**（课程价值 ~~999~~），含 AI创客圈1年 + 咿呀水晶1:1；推荐返利 100元/人不设上限
> **形式（2026-09-07 拍板·方案甲）**：13天两周 —— 1节开营直播 + 5节录播（30-45min/节，隔天解锁）+ 1节结营直播
> **产出原则**：所有内容优先复用已有资产——连载、理论笔记、探索营——再补充新内容
> **关系**：实战营是深度展开 → 探索营是加速版预告片（10min/节） → 短视频是切片引流
