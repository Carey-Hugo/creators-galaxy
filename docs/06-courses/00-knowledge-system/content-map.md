# 系统课「愿力实战」内容地图

> **定位**：199元（引流课学员专享199，含AI创客圈1年+咿呀水晶1:1）
> **时长**：1周，7节×30-45min（5节录播+1节开课直播+1节结营直播）
> **产出原则**：所有内容优先复用已有资产——连载、理论笔记、引流课——再补充新内容
> **关系**：系统课是深度展开 → 引流课是加速版预告片（10min/节） → 短视频是切片引流

---

## 一、7天内容总览

```
┌─────────────────────────────────────────────────┐
│  引流课（7天×10min）    系统课（7天×30-45min）   │
│  ────────────────       ────────────────        │
│  Day 1-2  共鸣层        Day 1  愿力认知深度课    │
│  Day 3-4  破局层        Day 2  时代诊断          │
│  Day 5-6  路径层        Day 3  愿力实战          │
│  Day 7    启程          Day 4  AI赋能           │
│                         Day 5  经济机制          │
│                         Day 6  案例复盘          │
│                         Day 7  启程+彩蛋         │

```

**核心逻辑**：引流课每一节 = 系统课对应模块的精华版（10min预告片）
系统课给深度、理论、实操、案例——引流课学员报课后看到**全新的内容**，没有一句话重复。

  → 只点出"不是你的问题"               → 完整理论+分析工具+三条路

Day 6 你的最小实践                       → 系统方法论+完整社区路径
  → 只给案例+清单                       → Web3逻辑+水晶机制
