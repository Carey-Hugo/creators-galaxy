## 三、内容复用关系总图

```
                 连载(19篇) ────┬──── 引流课(7天)
                    │          │         │
                    │          ▼         │
                    ├───→ 系统课(6模块) ←───┤
                    │          │          │
                    │          ▼          │
                    └──→ 短视频(N条) ←────┘
                              │
                              ▼
                          免费引流
                              │
                              ▼
                          → 引流课入口
```

**复用原则**：
1. **连载 → 课程**：连载的深度展开内容（2000-3000字）作为课程的理论素材库
2. **课程 → 短视频**：每个模块最精彩的1-2分钟切片做短视频
3. **短视频 → 引流课**：短视频结尾引导到引流课入口
4. **引流课 → 系统课**：Day 7 CTA + 折扣通道完成转化
5. **系统课 → 社区**：课程学员→益邻家园→持续生长
