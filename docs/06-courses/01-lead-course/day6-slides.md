## P3 三个问题，筛出你的开始（版式C · 自测表风格）

```
标题：三个问题，给答案做个体检
[全屏图] 三行筛选卡片（呼应 Day2 三标风格）：
  ① 我愿意做一年、不求回报吗？   → 不是3天，是365天
  ② 我愿意每周拿出30分钟吗？     → 不是每天3小时
  ③ 做完，有地方分享吗？         → 被看见，才养得大
底部：
  把"我好像想做点什么"
  过滤成"我下周就能开始的那件事"
```

**配图建议**：A dashboard 风格（三筛卡片，系列练习页统一）
