# 引流课「愿力探索」Day 1-2 逐字稿

---

## Day 1 · 四个词，你分得清吗？

**时长**：10分钟
**核心钩子**：大部分人一辈子都在追愿望，却从没触到过愿力。

---

### 【00:00-01:30】痛点开场

（面对镜头，放松、自然，像在跟朋友聊天）

你好，我是胡哥。

想先问你一个问题——

你过去三年里，有没有过这种感觉：终于觉得自己找到了"真正想做的事"？

那种感觉特别爽，对吧？浑身充满动力，觉得自己这次不一样了。

然后呢？三个月后，你又在看新机会。

一年换了三次方向，每次都觉得"这次是真的"，每次都在同一个地方摔倒。

你开始怀疑自己：是不是我不够坚持？是不是我太浮躁？是不是我这辈子就这样了？

**停——不是你的问题。**

我想告诉你一个你可能从来没想过的事情：你可能只是——用错了词。

**大部分人一辈子都在追「愿望」，却从没触到过「愿力」。**

这两个词，看着像，其实是完全不同的世界。

今天，我用10分钟帮你把四个词拆清楚：愿望、梦想、使命、愿力。你听完之后，马上就能判断——你过去三年那些方向，到底是哪一个。

---

### 【01:30-05:00】概念拆解：四层金字塔

（可以用手比划一个塔的形状，或者简单在白板上画）

这四层，一层一层往上走：

**第一层：愿望 ✋**

"我想换工作"、"我想减肥"、"我想学一门新技能"。

愿望的特征是什么？它是一种状态——我想要。但它没有动作，没有时间，没有代价。

愿望是消费心态。你许个愿，等着它实现。大部分人的大部分人生，就停在这一层。

**第二层：梦想 🌟**

"我要开一家咖啡店"、"我要成为自由职业者"。

比愿望好一点——它有画面了，有方向了。但梦想的致命问题是什么？

它是被动的。你梦到它、想到它，但它还悬浮在空中。

**第三层：使命 👣**

"我要帮助1000个人找到他们的愿力"、"我要让社区里的人生活更好"。

使命开始有重量了——它不是你想什么，是你觉得你应该做什么。

但使命也有一个陷阱：它太沉重了。很多人被使命压得喘不过气，因为"应该做的事"不一定是"你真正想做的事"。

**第四层：愿力 🔥**

"我愿意。"不是"我想要"、"我梦见"、"我应该"——是"我愿意"。

**愿望是"我想要"，愿力是"我愿意"。**

"我想要变有钱" → 许个愿，没了
"我愿意每天花2小时，坚持一年，做一件没人看的事" → 这是愿力

一个是被动等待，一个是主动选择。一个是消费心态，一个是创造心态。

愿力不是你想出来的——是做出来的。

---

### 【05:00-07:00】认知升级

（语气稍微慢一点，认真一点）

你发现没有？

我们从小被教育"要有一个梦想"、"找到你的使命"。

但很少有人告诉你——梦想和使命，都是通往愿力的一个台阶，不是终点。

终点是：**有没有一件事，你愿意做一辈子，哪怕没人看、没人夸、没人给钱？**

如果你找到了这件事——恭喜你，你找到愿力了。不管你现在赚多少钱、什么身份，你已经是人群里最幸运的那1%。

如果你还没找到——没关系，这才正常。大部分人一辈子都没触到这一层。你今天坐在这里听课，已经领先了。

---

### 【07:00-08:30】课后练习

好，今天的功课很简单。

打开你手机备忘录，写下：

**过去三年，你换过的三个方向。**
**然后判断：每次驱动你的，是愿望、梦想、使命、还是愿力？**

写完之后发到课程评论区。

不要觉得自己写得不好——这个练习的目的不是评判自己，而是看清楚自己站在四层金字塔的哪一层。

---

### 【08:30-10:00】留钩子

（眼神稍微近一点，有连接感）

写完的人，我想让你想一件事——

你说，如果真的有一种东西，同时具备三个特征：没人看你也愿意做、代价你能扛、而且做不完，越做越深——

那你觉得，你离这样的东西，还有多远？

明天，我教你三个标志，帮你测出来。

明天见。

## Day 2 · 3个标志，测你的愿力纯度

**时长**：10分钟
**核心钩子**：如果你对一件事做不到"可承诺、可承受、可生长"，那不是愿力。

---

### 【00:00-02:00】昨天回顾 + 引入

（自然开场，像接着聊昨天的话题）

昨天你写了三个方向，然后判断了每一层。

今天来对答案。

你写下的那些方向——为什么走不远？不是因为你不坚持，而是因为驱动它们的东西不够硬。

愿望太轻（一阵风就吹跑了），梦想有画面但没力量（喊完继续刷手机），使命太沉（背了很久就累了）——它们都有一个共同的问题：**不持久。**

那什么才持久？愿力。

愿力有三个标志。我用三个词概括——**可承诺、可承受、可生长。**

你用它给昨天写下的方向打分，打完你就知道哪个是真愿力，哪个是一时冲动。

---

### 【02:00-05:30】愿力三标

**第一标：可承诺**

不是一个合同，是一种感觉——**没人看你，你也做。**

你写公众号，没有人点赞、没有人转发、没有人夸你，你还在不在写？你还在想"明天写什么"？

如果有一个方向，你既没获得外界认可，也没赚到钱，但你做的时候很开心，做完觉得很充实——这就是可承诺。

反过来，如果一件事，你做完发朋友圈没人点赞，你就不想再做了——那它就只是愿望，不是愿力。

**第二标：可承受**

做什么事都有代价。代价就是你的时间、精力、钱、甚至关系。

你愿意为这件事付出什么？

不是"我能得到什么"——是"我愿意失去什么"。

很多人说"我想创业"，但他能承受的代价是"不影响我现在的收入"、"不加班"、"失败了还能回原公司"。

那你不是想创业，你是想"不创业就能成功"。

**真正的可承受是：这个代价我提前算好了，它发生了，我扛得住。**

哪怕最差的情况发生了——钱没了、时间花了、被人笑话了——我还是不后悔。

**第三标：可生长**

最容易被忽略的一标。

什么是可生长？就是你做这件事不会腻，不会到顶。

有些人打了一份工十年，做同样的流程——那不是愿力，是惯性。因为它在循环，没有生长。

愿力的标志是：**你做了一年，发现自己懂的更多了，问题也更难了，但你想继续。**

它不是重复劳动，是螺旋上升。每一年回头看，都是一个更深版本的自己。

**总结三标：**
- 可承诺 → 没人看你也做（内驱力）
- 可承受 → 最坏结果你扛得住（代价明确）
- 可生长 → 不是循环，是螺旋上升（越做越深）

---

### 【05:30-07:00】自测工具

好，现在拿出昨天写的那三个方向。

对每一个，用三标打分：

| 方向 | 可承诺(0-10) | 可承受(0-10) | 可生长(0-10) | 总分 |
|:--|:--|:--|:--|:--|
| 方向1 | | | | |
| 方向2 | | | | |
| 方向3 | | | | |

诚实打分。不要骗自己。

一个方向总分如果低于15分——它大概率不是你的愿力，你要么放弃它，要么降低期待（当作爱好而不是人生的主方向）。

如果一个方向总分超过20分——恭喜，你可能已经找到了。现在的问题是：你敢不敢认？

最高分那个方向，就是你现在最该做的事。

不是最赚钱的、不是最体面的、不是你爸妈期待的——是你自己三标打分最高的那个。

好了，如果你现在已经找到了那个三标都过20分的方向——我有一个问题要问你：

**为什么你明明知道自己该去做了，还是动不了？**

不是意志力问题——我们明天聊一个你意想不到的原因。
