## 1. 版式规则

PPT 尺寸：**10.00 × 5.62 inch**（横版 16:9 兼容 4:3 近似）

### 1.1 三种版式

| 版式 | 适用页 | 描述 |
|---|---|---|
| **A · 封面版式** | 每节首页（Day1 P1, Day2 P9, Day3-7 各 P1） | 左侧大标题+Day 序号+主讲，右下角 logo |
| **B · 左文右图版式** | 纯文字内容页（无背景图） | 左侧文字区（≤4.8 inch 宽），右侧配图区（4.0×3.0 inch @ 5.5, 1.3） |
| **C · 全屏背景图版式** | 概念图/示意图页（金字塔/对比/三标等） | 整页一张概念图，文字嵌入或叠加 |

### 1.2 关键坐标

| 元素 | 位置 | 尺寸 | 说明 |
|---|---|---|---|
| 封面 logo | (8.30, 3.50) | 1.50×1.90 inch | **所有封面统一** |
| 右侧配图 | (5.50, 1.30) | 4.00×3.00 inch | 留左 0.3 inch 间距 |
| 文字区宽度 | 收口 ≤4.8 inch | — | 避免与右侧配图重叠 |
| 正文起点 | left = 0.80 inch | — | 与版心对齐 |

## 1.5 全链路风格一致性原则（重要）

> **所有配图、信息图、背景图、生成图都必须与 PPT 课件本体保持匹配**。

| 维度 | 课件 PPT 标准 | 配图必须遵守 |
|---|---|---|
| 主色 | #1F3150 深蓝 | 配图底色或主色必须含此色 |
| 点缀 | #C9A96E 暖金 | 配图线条/光晕/主元素必须含此色 |
| 亮度 | 低明度，深色系 | 配图不允许高亮白/亮黄/饱和红 |
| 风格 | 几何/水彩/电影感 | 不用 Q 版漫画/扁平彩色/Material 风 |
| 元素 | 帆船/问号/对勾/几何符号 | 配图不出现 emoji/卡通人物/不相关图标 |
| 内容 | 紧扣本页文字主题 | 配图必须呼应本页关键词，禁止"通用配图" |

**禁止出现的元素清单**：
- ❌ 高饱和度的红/黄/绿撞色
- ❌ 卡通人物、3D 渲染、Q 版
- ❌ 与本页文字无关的"万能图"
- ❌ 浅色/白色背景（与深色 PPT 割裂）

**一致性自检 checklist**（每张图生成后必过）：
- [ ] 底色是深蓝系（不是白/浅/亮）？
- [ ] 主元素是暖金色调？
- [ ] 没有出现 PPT 风格外的元素（Q版/3D/撞色）？
- [ ] 视觉内容能呼应本页主题（不是"通用图"）？

## 2. 配图风格决策树

> **核心原则：内容决定风格，不强求统一**

```
内容是"结构化 / 对比 / 递进"        → A 几何卡片
内容是"品牌符号 / 愿景 / 启程意象"  → C 水彩帆船
内容是"高情绪 / 共情 / 孤勇"        → B 摄影（限用，慎用）
```

### 2.1 A 风格 · 几何卡片

- **底色**：#1F3150 深蓝
- **线条**：#C9A96E 暖金（1-2px 描边）
- **元素**：圆角矩形卡片 + 简单符号（问号/对勾/错号/数字）
- **不出现**：文字、人物、复杂装饰
- **典型应用**：3 问号卡片、错号vs对勾、3 标志、4 层金字塔

### 2.2 B 风格 · 真实摄影

- **场景**：35mm 电影感、剪影/光影、有孤独+希望张力
- **主调**：深蓝 + 暖金 / 黄昏
- **慎用**：每次课件最多 1 张，避免跳风格
- **典型应用**：灵魂拷问页、终极选择页（Day5/6 候选）

### 2.3 C 风格 · 水彩意象

- **底色**：深蓝水彩晕染 + 暖金笔触
- **核心符号**：帆船（与 logo 帆船系列呼应）
- **笔触**：手绘感、留白、有想象空间
- **典型应用**：愿景页、启程页、Day7 收束页

## 3. 配色与字体

| 元素 | 颜色 | 字号（PPT 内） |
|---|---|---|
| 背景 | #1F3150（深蓝）或 概念图 | — |
| 主标题 | #FFFFFF 白色 | 36-44pt |
| 强调字 | #C9A96E 暖金 | 24-32pt |
| 副标题 | #C9A96E 暖金 | 18-20pt |
| 正文 | #E8E8E8 浅灰 | 16-18pt |
| 分隔线 | #C9A96E 暖金细线 | — |
| Logo 主色 | #1F3150 深蓝 + #C9A96E 暖金 | — |

字体：思源宋体（标题）/ 思源黑体（正文），如系统无则回退到 PingFang/Microsoft YaHei

## 6. Day3-7 制作 checklist

每节 Day 课件制作时：

- [ ] 先列本页文案（dayN-slides.md）
- [ ] 按"风格决策树"为每张纯文字页选配图风格
- [ ] 文字区宽度收口 ≤4.8 inch（避免与配图重叠）
- [ ] 封面 logo 沿用 (8.30, 3.50) 1.50×1.90
- [ ] 生成配图后用 vision 验证 1 次（看布局/调性/有无错位）
- [ ] 导 PDF 预览全本 → 入库 → git commit
