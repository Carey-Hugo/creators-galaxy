## 三、7天完整大纲

### Day 1 · 四个词，你分得清吗？

**核心钩子**：大部分人一辈子都在追愿望，却从没触到过愿力。

| 模块 | 内容 |
|:--|:--|
| 痛点开场 | 是不是每次都觉得自己找到了"真正想做的事"，三个月后在找新方向？ |
| 概念拆解 | 愿望 ≠ 梦想 ≠ 使命 ≠ 愿力，四层金字塔拆解 |
| 认知升级 | 愿望是"我想要"，愿力是"我愿意"——消费心态 vs 创造心态 |
| 课后练习 | 写出过去三年换过的三个方向，判断每次驱动你的是哪个词 |
| 留钩子 | "明天教你三个标志，测你到底离愿力还有多远" |

### Day 2 · 3个标志，测你的愿力纯度

**核心钩子**：如果你对一件事做不到"可承诺、可承受、可生长"，那不是愿力。

| 模块 | 内容 |
|:--|:--|
| 昨天回顾 | 昨天你写的三个方向——为什么都走不远？因为缺愿力三标 |
| 愿力三标 | ① 可承诺（没人看你也会做）② 可承受（代价你能扛）③ 可生长（螺旋上升，不是循环） |
| 自测工具 | 三标打分表——诚实回答"这件事值得一辈子吗" |
| 课后练习 | 选一个你觉得最像愿力的事，三标打分，写在评论区 |
| 留钩子 | "那为什么你明明知道该换方向，却还是动不了？——不是意志力问题，是时代变了。" |

### Day 3 · 为什么你"想明白却活不出来"

**核心钩子**：不是你的问题，是时代变了。

| 模块 | 内容 |
|:--|:--|
| 引入 | 你三标都过了，为什么还在原地？因为你的努力和回报之间的因果链断了 |
| 框架 | 马克思主义 + AI替代：你不是变懒了，是你还在用旧地图走新路 |
| 痛点 | 学历贬值、年龄焦虑、关系消失——三大杀手的本质 |
| 留钩子 | "明天告诉你：AI时代，个人路在何方" |

### Day 4 · AI时代，个人何去何从

**核心钩子**：当个人奋斗失效，换赛道而不是换速度。

| 模块 | 内容 |
|:--|:--|
| 旧时代 vs 新时代 | 学历→工作→积累→退休 VS 愿力→实践→协作→生长 |
| 新逻辑 | 不是"你被AI替代"，是"你不会和AI协作" |
| 一句话 | 愿力定方向，AI给能力——人机共生才是2026的正确路径 |
| 留钩子 | "说了这么多大道理——有人已经在做了，明天给你看真实案例" |

### Day 5 · 创客星球：有人在做了

**核心钩子**：不是空谈，是真实发生的。

| 模块 | 内容 |
|:--|:--|
| 案例 | 益邻家园社区实践（不刻意提品牌名，讲实践事实） |
| 机制 | Web3经济如何让"愿意做的人"不被淘汰 |
| 激励 | 咿呀水晶：贡献不是白费的，每一个愿意的动作都有回响 |
| 留钩子 | "好，你别光听我的案例——你自己的最小实践是什么？" |

### Day 6 · 你的最小实践

**核心钩子**：不要等准备好，先做小事。

| 模块 | 内容 |
|:--|:--|
| 问题一 | 什么事你愿意做一年不求回报？ |
| 问题二 | 每周30分钟能做什么？ |
| 问题三 | 在哪里分享你的进度？ |
| 最小动作清单 | 今天就能做的3件事 |
| 留钩子 | "明天结课——我有个秘密要告诉你" |
