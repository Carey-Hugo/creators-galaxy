# 益邻家园ELINK · 搭建实操清单

> 平台：MoWa 水晶星球（Merculet）
> 状态：待动手搭建
> 目标：让用户能在益邻家园完成报名 + 看课 + 领水晶

---

## 第一阶段：基础搭建（今晚/明天完成）

### □ 1. 创建星球
- 路径：后台 → 星球配置 → 星球创建
- **星球名**：益邻家园ELINK愿力文明实践社区
- **水晶简称**：咿呀水晶 / YY
- **Slogan**：重塑邻里温情，点亮美好生活
- **Logo**：用益邻现有logo
- **宣传图**：建议一张社区氛围/邻里互助风格图

### □ 2. 设置星球主
- 路径：星球配置 → 星球主设置
- 把你设为星球主
- 设置星球内头像/昵称

### □ 3. 发射星球
- 复制链接 → 发到自己微信 → 点击成为原始居民
- 这条链接后续用于公众号/短视频引流

---

## 第二阶段：内容填充

### □ 4. 首页设计
- 路径：可视化 → 星球首页设计
- **顶部模式**：常规模式（展示Logo+品牌背景图）
- **背景图**：750×300 社区氛围图
- **组件布局建议**：

```
┌──────────────────────────┐
│  LOGO + 品牌背景图          │
├──────────────────────────┤
│  轮播图（活动/课程推荐）      │
├──────────────────────────┤
│  功能入口（课程/报名/水晶）   │
├──────────────────────────┤
│  我的水晶（用户看得见余额）   │
├──────────────────────────┤
│  星球店商品（引流课入口）     │
├──────────────────────────┤
│  星话题（社区讨论）          │
└──────────────────────────┘
```

### □ 5. 上架引流课商品
- 路径：商品管理 → 添加商品
- **类型**：虚拟商品（线上课程）
- **名称**：愿力启程·引流课
- **价格**：19.9元
- **说明**：5-7节视频课 + 社群权益
- **支付后动作**：自动发放咿呀水晶 + 拉入AI创客圈

### □ 6. 配置咿呀水晶
- 路径：任务体系 → 水晶配置
- **名称**：咿呀水晶
- **赠送规则**：报名引流课 → 同比例赠送水晶
- **后续用途**：兑换福利、参与社区活动

### □ 7. 内容管理（文章分类）
- 路径：内容管理 → 分类
- **建议分类**：
  - 📖 愿力启程（连载文章）
  - 💡 每周观点（Hugo的思考）
  - 🏡 社区实践（益邻活动）
  - 🎓 课程体系（引流课/系统课）

---

## 第三阶段：运营配置

### □ 8. 社群接入
- 路径：星球配置 → 社群设置
- 接入现有的益邻微信社群
- 设置管理员二维码

### □ 9. 任务体系
- 路径：任务配置
- **建议任务**：
  | 任务类型 | 内容 | 奖励 |
  |:--|:--|:--:|
  | 新手 | 完善个人资料 | 10水晶 |
  | 新手 | 首次阅读文章 | 5水晶 |
  | 分享 | 分享星球给好友 | 10水晶/次 |
  | 内容 | 参与话题讨论 | 5水晶/次 |
  | 购买 | 报名引流课 | 赠送水晶 |

### □ 10. 分销配置（如需）
- 路径：分销设置
- 开二级分销 + 队长躺赚
- 截胡逻辑视策略定

---

## 第四阶段：课程交付

### □ 11. 上传引流课内容
- 录播视频 → 商品详情页嵌入
- 或通过文章模板发布每节课内容
- 设置付费模式：**付人民币阅读**（19.9元）

### □ 12. 接入直播（可选）
- MoWa支持直播功能
- 可用于引流课答疑、公开课引流

---

## 第五阶段：对外推广

### □ 13. 公众号接入
- 微信后台 → 自定义菜单 → 跳转网页 → 益邻星球首页链接
- 关系链用「首页星球主链接」

### □ 14. 短视频/公众号引流
- 所有内容引流 → 最终落地益邻星球
- "扫码进入益邻家园，领取咿呀水晶"

---

## 搭建顺序建议

```
第一晚：阶段1（创建+发射）+ 阶段2（首页+商品）
第二晚：阶段3（社群+任务+分销）
第三晚：阶段4（上传课程内容）
完成后：阶段5（对外推广）
```

> ⚠️ 星球搭建好后，直播方案可以再评估——先用公众号+视频号做引流，成交落地益邻家园。
