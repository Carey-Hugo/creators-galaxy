## 二、核心漏斗（5级转化）

```
第一层：微信公众号（免费连载）
    → 书稿连载（免费）
    → 吸引最大流量
    → 每篇文末引导：「想系统学习？来小报童」
    → 沉淀关注者

第二层：小报童（付费订阅）
    → 书籍完整版 + 额外分析 + 白皮书预告
    → 门槛筛选：真正认同的行动者
    → 每篇引导：「想和其他探路者交流？来创客星球」

第三层：创客星球网站（精神家园 / 社区论坛）
    → 内容消费 + 社交 + 项目协作
    → 需要购买船票才能参与互动
    → 这是核心承载平台
    → 沉淀核心探路者

第四层：DAO治理（船上的人）
    → 贡献确权
    → 获得船票
    → 参与治理
    → 按贡献分配

第五层：价值增长（长期）
    → 平台价值增长
    → 船票升值
    → 贡献者获得回报
```

## 四、商业模式

### 4.1 核心原则

```
不是「平台圈钱」的逻辑
是「帮助参与者赚钱」的逻辑

平台的价值 = 参与者多赚的那部分

平台存在的意义 = 让「共同富裕」从口号变成可验证的现实

只有当一个创作者在这里赚到的 > 他在其他地方赚到的
创客星球的商业模式才真正成立
```

### 4.2 平台角色定位

```
我们不是「工具开发者」
我们是「工具市场的搭建者和运营者」

类似：
→ 淘宝：不是自己生产商品，是商品交易市场
→ App Store：不是自己开发App，是应用交易市场
→ 创客星球：不是自己开发AI工具，是AI工具和服务的交易市场
```

### 4.3 三条收入线

```
【收入线1：工具/服务交易抽成】
→ 探路者开发工具/服务 → 发布到平台
→ 需求方购买 → 资金走智能合约托管
→ 完成后自动释放给服务方
→ 平台抽 8%
→ 分销裂变：开发者设置分销佣金比例（如30%）
→ 平台从分销佣金中抽20%

【收入线2：项目协作抽成】
→ 有需求的探路者，或外部客户发布项目
→ 探路者们自由接单
→ 平台做：项目匹配 + 智能合约托管 + 争议调解
→ 抽成：8%

【收入线3：知识产品】
→ 书籍：《AI新时代——当机器学会分配》（¥49-99）
→ 课程：AI创作实战课 / DAO自组织实践课（¥299-999）
→ 白皮书完整版（¥199）
→ 模板包（¥99）
→ 分配：70%归创作者，20%归平台，10%进入社区激励池
```

### 4.4 分配机制

```
【原则】
→ 贡献者拿大头，平台只拿维持运营的最低比例
→ 8% 项目分成，是平台唯一的「收费」来源
→ 所有分配规则写入智能合约，没有人能篡改

【分配比例（待DAO讨论确定）】
→ 项目收入：92% 归贡献者，8% 归平台运营基金
→ 平台运营基金：用于服务器、工具、客服、后续开发
→ 知识产品收入：70% 归创作者，20% 归平台，10% 进入社区激励池

【传统平台 vs 创客星球】
→ 传统平台：抽30-50%，剩余才是你的
→ 创客星球：只抽8%，92%是你的
→ 规则透明可见，不存在暗箱操作
→ 贡献记录在链上，没有人能抹掉你的贡献
```

### 4.5 成本结构

```
【一次性成本】
→ 网站MVP开发：¥20,000-50,000（AI辅助开发可降低）
→ 智能合约开发：¥10,000-20,000（核心交易功能）
→ UI/UX设计：¥5,000（可自己做或外包）

【固定成本（每月）】
→ 服务器：¥200-500/月
→ AI API调用：¥0（平台不自研AI工具，不产生API成本）
→ 客服：¥0（初期自己扛）

【盈亏平衡点】
→ 最低成本运行：¥500/月
→ 有意义的运营：¥3,000/月（~100个付费用户可覆盖）
→ 小规模团队：¥10,000/月（~300个付费用户可覆盖）
```

### 4.6 阶段性目标

```
【第一阶段：验证期（1-3个月）】
→ 先打磨AI工具/服务，发布免费版
→ 收集100个真实用户反馈
→ 关键指标：免费用户数、转化率

【第二阶段：启动期（3-6个月）】
→ 引入第一批真实项目需求方
→ 招募第一批接单者
→ 上线智能合约托管功能
→ 关键指标：项目数、GMV、结算成功率

【第三阶段：成长期（6-12个月）】
→ 付费用户达到300+
→ 月GMV达到¥100,000+
→ 平台月收入达到¥10,000+
→ 关键指标：月收入覆盖运营成本

【第四阶段：扩张期（12个月+）】
→ 建立DAO治理，引入代币激励
→ 将平台运营权逐步移交给DAO
→ 发行平台代币（用于治理投票 + 激励）
```

## 七、积分体系

### 7.1 积分获取规则

```
【行为积分】
→ 注册：+10分
→ 每日签到：+1分
→ 发布内容（文章/想法）：+5分
→ 发布评论：+2分
→ 被评论：+1分/条
→ 被转发：+3分/次
→ 被打赏：+积分（按打赏金额等比）
→ 转发分享（带追踪码）：按转化效果给积分
→ 参与投票：+2分
→ 参与项目协作：+贡献积分（按项目金额比例）

【新手任务】
→ 完善个人档案：+5分
→ 第一次评论：+2分
→ 第一次发布内容：+5分
→ 第一次被打赏：+3分
→ 第一次递名片成功：+3分
```

### 7.2 积分用途

```
【当前阶段（Phase 1）】
→ 兑换平台虚拟权益
→ 社区投票权重加成（积分越高，投票权重越大）
→ 未来可兑换：知识星球优惠券、船票升级、项目优先参与权

【未来阶段（Phase 2-3）】
→ 兑换船票（DAO成员凭证）
→ 解锁高级功能
→ 项目分红权重
→ 平台代币激励
```

### 7.3 积分透明

```
→ 所有积分变动记录公开可查
→ 积分排行榜（可选择隐藏）
→ 积分来源说明
→ 防止刷分的机制（行为验证）
```

```
→ 开发工具 → 发布到平台 → 设置分销佣金比例
→ 例如：设置30%分销佣金
→ 每有人通过你的链接购买，你获得30%的分销奖励

【分销者】
→ 转发工具链接 → 有人通过你的链接购买
→ 你获得约定比例的分销佣金（开发者设置）
→ 每次传播都有收益追踪（平台内追踪）

【平台】
→ 工具交易：抽8%
→ 分销佣金：从开发者设置的佣金中抽20%（平台拿小头）
```

### 9.2 分销佣金举例

```
工具定价：¥100
开发者设置分销佣金比例：30%

→ 用户通过分销者链接购买
→ 分销者获得：¥100 × 30% = ¥30
→ 开发者获得：(¥100 - ¥30) × 80% = ¥56
→ 平台获得：(¥100 - ¥30) × 20% + ¥100 × 8% = ¥14 + ¥8 = ¥22
```

### Phase 2 新增：DApp Hub / Skill Store

```
【定位】
→ 不是普通的工具站
→ 是「去中心化创客工具的 App Store」
→ 创客星球 = AI时代创作者 DApp 的入口

【DApp分类】
→ AI工具类（Agent / Skill / 提示词模板）
→ 智能合约类（开源合约模板 / 可视化合约生成器）
→ 效率工具类（项目管理 / 协作看板 / 贡献记录）
→ 插件/接口类（浏览器插件 / Telegram Bot / ChatGPT插件）
→ 内容模板类（书籍模板 / 白皮书模板 / 建站模板）

【开源 vs 商业】
→ 开源版：源码公开，可免费使用/审计/fork
→ 商业版：专业功能/支持/定制，开发者自主定价
→ 平台只抽8%，92%归开发者

【Git集成】
→ 探路者关联GitHub/Gitee仓库
→ 平台展示：项目地址、Star数、贡献者
→ 自动同步：Git更新 → 平台自动更新
→ 一键Fork：复制到自己的空间，自主修改/发布

【Skill/Agent Marketplace】
→ 提交审核（确保不是恶意代码）→ 上架
→ 形态：提示词模板 / 工作流配置 / Agent配置 / 训练数据集
→ 对开发者：好的Skill被更多人用 = 被动收入
→ 对用户：不用从零开始，站在别人肩膀上
```

### Phase 3（6-12个月）：DAO治理

```
新增：
```

## 十一、UI/UX 设计方向

### 11.1 视觉风格

```

→ 调性：有思想、有深度、有温度

【颜色系统】

→ Electric Cyan：#00e5ff（科技/电路/去中心化）
→ Warm Gold：#ffd700（东方智慧/人类/共同体）
→ Silver：#c0c0c0（文字/连线）
→ Deep Crimson：#8b0000（传统分配批判）
```

### 11.2 字体建议

```
→ 标题：思源黑体（Noto Sans）/ 或苹方
→ 正文：系统默认，清晰易读
→ 英文：Inter / Roboto
```

### 11.3 布局原则

```
→ 信息密度适中，不要太挤
→ 留白充足，阅读舒适
→ 移动端优先（70%流量来自手机）
→ 夜间模式支持
```

## 十二、风险与应对

```
【风险1：社区冷启动】
→ 对策：小范围邀请（首批探路者）+ 公众号导流 + 内容驱动

【风险2：工具/服务质量参差不齐】
→ 对策：平台认证体系 + 用户评价 + 社区仲裁

【风险3：刷积分/刷单】
→ 对策：行为验证 + 积分变动审核 + 举报机制

【风险4：政策合规（Web3/区块链）】
→ 对策：前期以「积分」为主，不发代币；代币阶段找专业法律顾问

【风险5：成本超出预期】
→ 对策：Phase 1 用开源方案（WordPress/Discourse），降低开发成本
```
