## 二、核心漏斗（5级转化）

```
第一层：微信公众号（免费连载）
    → 书稿连载（免费）
    → 吸引最大流量
    → 每篇文末引导：「想系统学习？来小报童」
    → 沉淀关注者

第二层：小报童（付费订阅）
    → 书籍完整版 + 额外分析 + 白皮书预告
    → 门槛筛选：真正认同的行动者
    → 每篇引导：「想和其他探路者交流？来创客星球」

第三层：创客星球网站（精神家园 / 社区论坛）
    → 内容消费 + 社交 + 项目协作
    → 需要购买船票才能参与互动
    → 这是核心承载平台
    → 沉淀核心探路者

第四层：DAO治理（船上的人）
    → 贡献确权
    → 获得船票
    → 参与治理
    → 按贡献分配

第五层：价值增长（长期）
    → 平台价值增长
    → 船票升值
    → 贡献者获得回报
```

## 四、商业模式

### 4.1 核心原则

```
不是「平台圈钱」的逻辑
是「帮助参与者赚钱」的逻辑

平台的价值 = 参与者多赚的那部分

平台存在的意义 = 让「共同富裕」从口号变成可验证的现实

只有当一个创作者在这里赚到的 > 他在其他地方赚到的
创客星球的商业模式才真正成立
```

### 4.2 平台角色定位

```
我们不是「工具开发者」
我们是「工具市场的搭建者和运营者」

类似：
→ 淘宝：不是自己生产商品，是商品交易市场
→ App Store：不是自己开发App，是应用交易市场
→ 创客星球：不是自己开发AI工具，是AI工具和服务的交易市场
```

### 4.3 三条收入线

```
【收入线1：工具/服务交易抽成】
→ 探路者开发工具/服务 → 发布到平台
→ 需求方购买 → 资金走智能合约托管
→ 完成后自动释放给服务方
→ 平台抽 8%
→ 分销裂变：开发者设置分销佣金比例（如30%）
→ 平台从分销佣金中抽20%

【收入线2：项目协作抽成】
→ 有需求的探路者，或外部客户发布项目
→ 探路者们自由接单
→ 平台做：项目匹配 + 智能合约托管 + 争议调解
→ 抽成：8%

【收入线3：知识产品】
→ 书籍：《AI新时代——当机器人学会分配》（¥49-99）
→ 课程：AI创作实战课 / DAO自组织实践课（¥299-999）
→ 白皮书完整版（¥199）
→ 模板包（¥99）
→ 分配：70%归创作者，20%归平台，10%进入社区激励池
```

### 4.4 分配机制

```
【原则】
→ 贡献者拿大头，平台只拿维持运营的最低比例
→ 8% 项目分成，是平台唯一的「收费」来源
→ 所有分配规则写入智能合约，没有人能篡改

【分配比例（待DAO讨论确定）】
→ 项目收入：92% 归贡献者，8% 归平台运营基金
→ 平台运营基金：用于服务器、工具、客服、后续开发
→ 知识产品收入：70% 归创作者，20% 归平台，10% 进入社区激励池

【传统平台 vs 创客星球】
→ 传统平台：抽30-50%，剩余才是你的
→ 创客星球：只抽8%，92%是你的
→ 规则透明可见，不存在暗箱操作
→ 贡献记录在链上，没有人能抹掉你的贡献
```

### 4.5 成本结构

```
【一次性成本】
→ 网站MVP开发：¥20,000-50,000（AI辅助开发可降低）
→ 智能合约开发：¥10,000-20,000（核心交易功能）
→ UI/UX设计：¥5,000（可自己做或外包）

【固定成本（每月）】
→ 服务器：¥200-500/月
→ AI API调用：¥0（平台不自研AI工具，不产生API成本）
→ 客服：¥0（初期自己扛）

【盈亏平衡点】
→ 最低成本运行：¥500/月
→ 有意义的运营：¥3,000/月（~100个付费用户可覆盖）
→ 小规模团队：¥10,000/月（~300个付费用户可覆盖）
```

### 4.6 阶段性目标

```
【第一阶段：验证期（1-3个月）】
→ 先打磨AI工具/服务，发布免费版
→ 收集100个真实用户反馈
→ 关键指标：免费用户数、转化率

【第二阶段：启动期（3-6个月）】
→ 引入第一批真实项目需求方
→ 招募第一批接单者
→ 上线智能合约托管功能
→ 关键指标：项目数、GMV、结算成功率

【第三阶段：成长期（6-12个月）】
→ 付费用户达到300+
→ 月GMV达到¥100,000+
→ 平台月收入达到¥10,000+
→ 关键指标：月收入覆盖运营成本

【第四阶段：扩张期（12个月+）】
→ 建立DAO治理，引入代币激励
→ 将平台运营权逐步移交给DAO
→ 发行平台代币（用于治理投票 + 激励）
```

## 七、积分体系与收益共享

> **核心设计理念：** 平台不是少数人的印钞机，而是所有贡献者的共同事业。谁为平台创造价值，谁就分享平台的成长红利。

### 7.1 双积分体系

```
【MKT = 贡献积分】
→ 功能型，可流通
→ 可通过行为获取，也可充值购买
→ 用于平台内消费（参与项目、兑换权益等）

【STAR = 治理积分】
→ 权益型，不可购买，只能贡献获得
→ 代表用户在平台的真实贡献度
→ 决定用户分红权重和治理权限
```

### 7.2 积分获取规则

**MKT积分（可购买+可行为获取）：**

| 行为 | 获得积分 | 说明 |
|------|---------|------|
| 注册 | +10 MKT | 一次性 |
| 每日签到 | +1-5 MKT | 连续天数越多越多 |
| 发布优质内容（被精华） | +20 MKT | 每次 |
| 发布优质回复 | +5 MKT | 每次 |
| 发起话题（参与>10人） | +10 MKT | 每次 |
| 帮助解答被采纳 | +30 MKT | 每次 |
| 邀请新用户注册 | +20 MKT | 直接邀请 |

| 参与平台活动 | +10-100 MKT | 活动奖励 |
| 充值购买 | 1元=1MKT | 官方渠道 |

**STAR积分（只能贡献获得，不可购买）：**

| 优先参与权 | 500 STAR | 新项目早期参与 |
| 竞选理事 | 10000 STAR | 锁定一年 |

### 7.4 积分透明与防滥用

```
【积分透明】
→ 所有积分变动记录公开可查
→ 积分排行榜（可选择隐藏）
→ 积分来源说明清晰

【防刷分机制】
→ 限制每个IP/设备每日签到次数
→ 优质内容需人工或算法审核
→ 积分获得设置冷却时间

【关键原则】
→ STAR不可购买，只能贡献获得
→ MKT可购买，但购买不参与分红权重
→ 分红权重只看STAR，不看MKT
```

### 7.5 平台收益分配与用户分红机制

#### 7.5.1 收入来源

```
1. 工具市场交易抽成（8%）
2. 船票收入（¥99/年）
3. 知识产品收入（书籍、小报童、课程等）
4. 项目协作服务费（托管费、验证费等）
```

#### 7.5.2 收入分配规则

```
┌─────────────────────────────────────────────────────┐
│              平台总收入（税后）                        │
│                                                     │
│   ┌──────────┐         ┌───────────────────┐        │
│   │ 运营成本  │         │    可分配利润      │        │
│   │ （预留）  │         │ = 总收入 - 运营成本 │        │
│   └──────────┘         └───────────────────┘        │
│                         │                           │
│          ┌──────────────┼──────────────┐            │
│          ▼              ▼              ▼            │
│    ┌──────────┐   ┌──────────┐   ┌──────────┐      │
│    │ 核心团队  │   │ 投资者   │   │ 公共基金池 │      │
│    │   50%    │   │   25%    │   │   25%    │      │
│    └──────────┘   └──────────┘   └──────────┘      │
│                                    │                │
│                         ┌──────────┴──────────┐     │
│                         ▼                      ▼     │
│                   ┌──────────┐          ┌────────┐  │
│                   │ 用户分红 │          │ 事业合伙人│ │
│                   │   50%   │          │   50%   │  │
│                   │(=公共基金│          │(按STAR持│  │
│                   │  池的50%)│          │有量分配)│  │
│                   └──────────┘          └────────┘  │
└─────────────────────────────────────────────────────┘
```

**简化公式：**

```
用户可分配总额 = 可分配利润 × 25%

每个用户的分红 = 用户可分配总额 ×（用户STAR ÷ 全平台STAR总流通量）
```

#### 7.5.3 分红细则

| 项目 | 规则 |
|------|------|
| 分红周期 | 每季度发放一次 |
| 分红门槛 | STAR持有量≥100（不足不参与当期分红） |
| 分红形式 | MKT积分发放 |
| 锁仓机制 | 上线3年内，分红收益的50%锁仓6个月 |
| 税收处理 | 由用户自行申报 |

**分红示例：**

```
假设：
- 某季度平台可分配利润 = ¥100,000
- 全平台STAR总流通量 = 1,000,000 STAR
- 用户A持有 STAR = 10,000 STAR

计算：
- 用户可分配总额 = ¥100,000 × 25% = ¥25,000
- 用户A的分红 = ¥25,000 ×（10,000 / 1,000,000）
- 用户A本季度分红 = ¥250 MKT
```

#### 7.5.4 估值与增值

```
估值模型：平台估值 = 平台年度可分配利润 × 估值倍数

估值倍数参考：
- 早期（0-1年）：3-5倍
- 成长期（1-3年）：5-10倍
- 成熟期（3年+）：10-20倍

用户持有STAR的潜在收益：
1. 分红收益 → 平台利润分红（每季度）
2. 增值收益 → 平台估值增长 → STAR对应权益增值
3. 治理收益 → 参与DAO投票，影响平台发展方向
```

#### 7.5.5 上链后的实现

```
【暂不上链阶段（当前）】
- 用数据库记录每个用户的MKT和STAR
- 分红计算由平台运营方执行
- 定期公示积分总数和分红金额
- 用户可随时查询自己的积分和分红记录

【上链后（未来）】
- MKT映射为功能型代币（Utility Token）
- STAR映射为权益型代币（Equity Token）
- 分红逻辑写入智能合约
- 自动执行，无需人工干预
- 分红直接从合约地址转给用户钱包
- 不可篡改，不可赖账
```

## 九、分销裂变机制

### 9.1 机制说明

```
【工具开发者】
→ 开发工具 → 发布到平台 → 设置分销佣金比例
→ 例如：设置30%分销佣金
→ 每有人通过你的链接购买，你获得30%的分销奖励

【分销者】
→ 转发工具链接 → 有人通过你的链接购买
→ 你获得约定比例的分销佣金（开发者设置）
→ 每次传播都有收益追踪（平台内追踪）

【平台】
→ 工具交易：抽8%
→ 分销佣金：从开发者设置的佣金中抽20%（平台拿小头）
```

### 9.2 分销佣金举例

```
工具定价：¥100
开发者设置分销佣金比例：30%

→ 用户通过分销者链接购买
→ 分销者获得：¥100 × 30% = ¥30
→ 开发者获得：(¥100 - ¥30) × 80% = ¥56
→ 平台获得：(¥100 - ¥30) × 20% + ¥100 × 8% = ¥14 + ¥8 = ¥22
```
