## 一、五层框架总览

```
道 → 方向/源头（为什么存在，顺着什么方向走）
法 → 结构/秩序（靠什么稳定成立，可复制不跑偏）
术 → 技法/灵动（法进入现场后的活功夫，填补现实与法之间的空隙）
器 → 承载/协同（记录、放大经验，让承接更稳定可追踪）
用 → 验证/生成（现场检验是否真实起作用，反馈升级体系）
```

**一句话总结**：道定方向，法立结构，术因现场，器作承载，用见真章。

| 层级 | 回答的问题 | 关键词 | 特点 |
|:--|:--|:--|:--|
| 道 | 为什么存在？顺着什么方向？ | 趋势、因果、约束 | 方向性、源头性 |
| 法 | 靠什么稳定成立？如何复制？ | 结构、秩序、边界 | 稳定性、可复制 |
| 术 | 现场怎么做？何时接何时推？ | 节奏、取舍、时机 | 灵动性、场景化 |
| 器 | 用什么承载协同记录？ | 承载、记录、放大 | 工具性、系统性 |
| 用 | 真的起作用了吗？ | 作用、验证、反馈、生成 | 检验性、闭环性 |

## 二、道 · 智慧教练的方向

### 2.1 智慧教练为什么存在？

> "智慧教练不是为了培养普通的教练，而是为了回应在 AI 文明时代更深的需要。"

**AI 文明时代的核心问题**：随着 AI 迅猛发展，赛道会发生什么变化？人的需求会发生什么变化？智慧教练的行当又会发生什么变化？

### 2.2 智慧教练的四大核心任务

| # | 任务 | 内涵 |
|:--|:--|:--|
| 1 | **生命主权的归还** | 帮助人回到自己，不把主权交出去。在 AI 会讨好你、迎合你的时代，能否穿越潜意识和小需要，看到深层次的自己？ |
| 2 | **愿力的识别** | 帮助一个生命真正看见自己的主轴，而不是停在表面的愿望。区分：愿望 / 梦想 / 使命 / 愿力（四词区分框架源于 **Hugo原创**，在公众号书籍连载中首发，后被大象老师分享传播、朱斌老师引用） |
| 3 | **人机共生的实践** | 不是"更会用 AI"，而是在正确关系中共同生成。人负责感知（感知对方的真实、情绪、敷衍），AI 负责结构化（在最短时间内从上百个信息点中找到主轴） |
| 4 | **文明节点的长成** | 帮助个体、组织、空间、项目逐渐形成新的文明节点——一个有关键影响力的位置，帮助更多人在土壤中"心无挂碍地做最好的自己" |

### 2.3 智慧教练不是什么（边界）

> ❌ 不是普通的教练  
> ❌ 不是陪聊的角色（只会说好听、只会赞美、只让别人好过）  
> ❌ 不是一个课程的销售  
> ❌ 不是身份的包装  
> ❌ 不是"更会用 AI 的人"  
> ❌ 不是替别人做主的人

### 2.4 智慧教练的核心工作

| 核心动作 | 说明 |
|:--|:--|
| 识别愿力 | 先看到愿力状态，不被短期机会带跑 |
| 承接关系 | 承接被点亮的人，不让其悬空。需要一个"土壤"/结构来接住 |
| 协同智慧体 | 人机协同，感知 + 结构化 = 新可能性涌现 |
| 校准状态 | 帮助对方校准"我到底想做什么" |
| 推动行动 | 从最小实践开始，"这一周只做三件事" |
| 转译文明 | 帮助理解"什么是愿力文明""什么是 AI 时代" |
| 陪伴归位 | 像朋友陪着走过黑暗隧道，打手电筒问问题，不替你走路 |

## 三、法 · 智慧教练的体系结构

### 3.1 法的四层结构

```
第一层 · 上位承接法（个体层）
  → 每一个智慧教练必须守住的东西
  → 生命主权法、愿力优先法、复盘迭代法、底线边界法

第二层 · 团队本体法（团体层）
  → 角色分工（愿力接引师 / 启愿师 / 智慧教练）
  → 分级体系（L1 / 准L2 / L2 / L3 / L4）
  → 准入法、训练法、上岗法、交付与转交法

第三层 · 业务场景法（场景层）
  → 愿力星门、智慧陪伴、生命花园、节点判断
  → 每个场景有独立的流程方法

第四层 · 分配回流法（价值层）
  → M515 价值记录与回流
  → 文明账本：善意被记录、劳动被回应
```

### 3.2 上位承接法（个体层·核心六法）

| 法 | 内容 |
|:--|:--|
| **生命主权法** | 帮助人看见自己，不替人决定。用"神稳态"觉察：我有没有把主权交出去？有没有变成"神仙"状态？ |
| **愿力优先法** | 先看到愿力状态，不被短期机会带跑。核心问题："如果一切都如你所愿，你最希望发生的是什么？""钱不是问题、时间不是问题、精力不是问题，你最想做什么？" |
| **不抢主权法** | 不抢别人的主权，也不乱承接 |
| **土壤承接法** | 要用一个结构来接住被点亮的人，不能悬空。"醒过来的人挺多，但很多醒过来的人没有土壤能接得住。" |
| **复盘迭代法** | 每个案例都做复盘，用 AI 生成报告，加速成长 |
| **底线边界法** | 不做心理治疗、不做医疗、不做专业法律投资判断——只是智慧陪伴 |

### 3.3 团队角色体系

| 角色 | 定位 | 收入模式 |
|:--|:--|:--|
| **愿力接引师** | 向别人介绍愿力星门是什么 | 介绍费 |
| **启愿师** | 通过 AI 人机共生智慧体，帮助客户看见生命愿力，出报告，陪3个月 | 5000元/人 → 2500元给启愿师 + M515 |
| **智慧教练** | 智慧陪伴：陪伴生命品牌、愿力型组织成长发展 | 按项目 |

> 启愿师经济模型：每月陪伴 4 人 × 2500 = **1万元**（副业），全职 20+天 × 5000 = **4万+**

### 3.4 分级体系

| 级别 | 状态 | 权限 |
|:--|:--|:--|
| L1 | 起点，有卡点未完成和解，边界感不够 | 学习成长 |
| 准L2 | 心性稳定到位，有边界感 | 可分配生态共建工作 |
| L2-L4 | 需一对一沟通确认 | 更高级别权限 |

> "分级不是给人盖戳，而是一个对当下状态的反馈。"

## 四、术 · 智慧教练的场景技法

> "术不是套路，是法进入现场后的活功夫。"

### 四大场景

| 场景 | 核心动作 | 关键要点 |
|:--|:--|:--|
| **愿力星门术** | 打开 → 识别 → 校准 → 分流 | 不要误判、不要讲满、不要悬空 |
| **智慧陪伴术** | 承接 → 推进 → 稳住 → 转交 | 看清阶段、识别卡点、守住边界 |
| **生命花园术** | 接人 → 识别 → 分流 → 收拢 | 处理物理场域里的复合关系和现场流动 |
| **节点判断术** | 识别 → 定位 → 匹配 → 安放 | 判断人/团体/组织/NGO 的愿力方向和共建可能 |

## 五、器 · 智慧教练的工具系统

> "器不能替代方向的判断、生命主轴、现场分寸、真实关系、最终承担。"

### 智慧教练的七类器

| 类型 | 功能 |
|:--|:--|
| 记录器 | 将经验沉淀为可追溯的数据 |
| 协同器 | 人机协同，AI智慧体辅助 |
| 分配与回流器 | M515 价值记录系统 |
| 法务与制度器 | 规则和边界文件 |
| 训练器 | 共生营、线下营、人机共生班 |
| 交付器 | 三个月交付的标准流程 |
| 复盘器 | 每一次沟通的AI复盘报告 |

### 使用器的原则

| 器不能替代的 | 原因 |
|:--|:--|
| 方向的判断 | 器没有方向感 |
| 生命的主轴 | 器不知道你是谁 |
| 现场的分寸 | 器感知不到场域 |
| 真实的关系 | 器不是人 |
| 最终的承担 | 每一个交付由智慧教练承担 |

> "真正决定器是否有用的，是道是否清、法是否稳、术是否准——这是一脉相承的。"

## 六、用 · 现场验证与体系升级

> "用，不是执行，是现场的检验。"

### 用的核心任务

| 任务 | 说明 |
|:--|:--|
| 点亮人 | 有没有真正起到作用？ |
| 承接人 | 有没有接触人、接住人？ |
| 推动人 | 有没有推动行动？ |

### 反馈闭环

```
当下真实场景
    ↓
调用道法术器
    ↓
发生作用、采集反馈
    ↓
校准升级
    ↓
沉淀为新的样本、新规则、新工具
    ↓
反哺道法术器
```

> "用的成熟不是越做越多，而是每一次真实使用都能帮助系统升级。"

## 九、关键金句摘录（创作引用素材）

> "愿望是'我想要'，愿力是'我愿意'。"

> "道不是口号，而是方向；不是高度，而是源头。"

> "醒过来的人挺多，但很多醒过来的人没有土壤能接得住。"

> "有的人是醒过来，然后又闭上了眼睛。你无法叫醒一个装睡的人。"

> "神稳态——我是不是把主权握在自己手里？我有没有把自己变成很神仙的状态？"

> "智慧教练不是为了讲清楚，而是为了让人被点亮、被承接、被推动。"

> "进入智慧教练不是先给自己一个身份，而是先找到自己愿意开始长出来的位置。"

> "让陪伴有结构，让愿力有承接，让人重新回到人。"
