## 📌 永久教训（已沉淀到 skill）

1. 长标题（>22字）+ 引号 + 标点 → AI 生成错字风险极高
2. PIL 系统字体（wqy-zenhei/Droid）回退错字："绕"→"绝/绳"，"越"→"趣"
3. vision_analyze 中文 OCR **不可信**，自检必须用 Python `hex(ord())`
4. 同义安全词（已验证）：躲不开/避不开/逃不开/跳不开
5. **方案抉择**：AI 全文字 vs AI 无字底图+PIL 叠字
   - 优先 PIL 叠字（零错字、可控）
   - 即梦全文字：高风险但省事，需生 2-4 张挑选
