## 一、姊妹篇统一设计原则（V1.0）

> 原文：【公共区】姊妹篇统一设计原则（V1.0）｜制定日期：2026-08-08 | 双工作台共同遵守
> 用途：确保A书《当机器人学会分配》与B书《当每个人愿力启程》——独立成篇、相互连贯、一脉相承
> 适用范围：两书后续所有框架调整、章节撰写、素材引用，一律以本原则为准

### 1.1 总纲：姊妹篇的定义

两本书不是"上下册"（A读完全本才能读B），也不是"合集"（两本独立无关），而是：
- **独立成篇**：任何一本单独阅读都完整自洽
- **相互连贯**：共享同一概念体系、素材库、金句库、案例谱系
- **一脉相承**：A书回答"为什么、凭什么"，B书回答"怎么练、怎么做"，认知线→实践线贯通

### 1.2 结构分工：认知与实践双线

| 维度 | A书（认知卷） | B书（实践卷） |
|---|---|---|
| 方法 | 演绎法 | 归纳法 |
| 主线 | 势 → 道 → 法 | 术 → 器 → 用 |
| 气质 | 哲科思想求索 | 最佳实践求索 |
| 回答 | 为什么变？凭什么这么分？ | 怎么练？怎么用？怎么做？ |
| 读者收获 | 看懂时代、建立世界观 | 拿到方法、开始行动 |

### 1.3 法术分工原则（解决"法"与"术"重叠）

- A书的"法" = **宏观制度设计**：面向系统与结构（分配制度、治理规则、组织形态），回答"规则该怎么立"
- B书的"术" = **微观个人修炼**：面向个体与行动（愿力练习、落地动作、日常习惯），回答"人该怎么练"
- 同一方法论出现时，A书讲原理与制度层，B书讲操作与动作层，**禁止重复展开**

### 1.4 卷篇锚点对照表（解决章节不对称）

| A书 | B书 | 呼应关系 |
|---|---|---|
| 导论：分配成为第一问题 | 序章：时代背景 | 同一时代诊断，两种表述 |
| 卷上·变局（第1-3章） | 上篇·术（第1-4章） | 时代大势 → 个体出路 |
| 卷中·求索（第4-8章） | 中篇·器（第5-6章） | 哲思原理 → 工具运用 |
| 卷下·大道（第9-12章） | 下篇·用（第7-9章） | 制度设计 → 实践落地 |
| 终章：文明的下一站 | 全书（实践闭环） | 接力 + 回扣 |

### 1.5 双向引用机制（解决单向接力）

**B书每章新增小节「理论锚点」**：

| B书章节 | 回扣A书 |
|---|---|
| 第一章 愿力是什么 | A书第6章 价值论重构 |
| 第二章 愿力觉醒 | A书第6章（愿力三标志） |
| 第四章 愿力系统设计 | A书第4章 系统思维 |
| 第五章 愿力×AI分工 | A书第8章 控制与反控制 |
| 第七章 组织愿力 | A书第11章 组织演进 |
| 第八章 探路者案例 | A书第12章 益邻家园ELINK |
| 第九章 愿力文明 | A书第10章 分配制度设计 |

**A书每章标注「实践落点」**：各章末尾脚注指向B书对应章节，如"本结论的实践验证见B书第八章"。

### 1.6 共享底层（两书共用的同一套资产）

- **核心概念**：愿力、愿力实践、愿力实践型组织、第三条路、参与即股东创造即确权、控制型→共生型、系统思维五步法、3-5个信任节点、被看见/被记录/被回馈（术语表见第七章）
- **案例谱系四层**：组织级（胖东来）/ 公司级（梁文锋）/ 社区级（益邻）/ 个人级（作者自述）——A书用理论层，B书用实践层
- **金句库**：两书可互相引用，标注出处
- **素材库**：26篇连载+新文，按"主映射/次映射"归属，不重复使用

### 1.7 执行检查单（每次框架升版时核对）

1. 两书章节是否遵循卷篇锚点对照？
2. 同一概念是否避免重复展开（A书原理/B书操作）？
3. 双向引用是否标注（B书锚点/A书落点）？
4. 新素材是否登记主/次映射归属？
5. 术语是否使用公共区术语表口径？

### 1.8 版本记录

### 4.3 卷上｜变局（势：AI 生产力跃迁趋势推演）

**导论 分配成为第一问题**

- 🔗 实践落点：B书序章·时代背景（同一时代诊断，两种表述）
