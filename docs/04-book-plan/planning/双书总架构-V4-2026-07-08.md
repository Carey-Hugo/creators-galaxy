## 一、双书结构（势道法 + 术器用）

### 📕 A 书《AI 新时代——当机器人学会分配》= **势道法层（理论篇）**

**副标题（7/8 胡哥拍板微调）**：
> AI 先进生产力跃迁背景下，人类社会文明演进的哲科思想求索

**方法论**：**主要采用演绎法讲述**

**核心命题**：
- **势**：AI 时代生产关系变革的发展趋势方向
- **道**：AI 先进生产力跃迁驱动新型生产关系变革的底层逻辑规律
- **法**：贡献记录价值分配的体系化科技、规则与方法论

**定位**：共同富裕探路者的**思想理论求索**

**目标读者**：
- 想理解 AI 时代为什么会变的思考者
- 想看清分配机制底层规律的政策研究者 / 学界
- 想用"道"指导个人决策的愿力探索者

### 📗 B 书《AI 新时代——当每个人愿力启程》= **术器用层（实践篇）**

> ✅ **2026-07-08 胡哥拍板定名**
> **核心理由**：愿力文明 = 群体觉醒命题，不是单点"我"叙事。光"我"愿力启程不能让文明进入新阶段，必须每个人觉醒。
> **副标题（7/8 胡哥拍板微调）**：
> > AI 先进生产力跃迁背景下，共同富裕探路者们的最佳实践求索

**方法论**：**主要采用归纳法讲述**

**核心命题**：
- **归纳法主轴**：基于势、道、法的**具体术、器、用的凝练总结**
- **核心案例**：以**益邻家园**为主要代表的**所有共同富裕探路者们的具体可行的宝贵实践案例经验分享**
- **术**：现场功夫（共识系统 / 土壤承接 / 最小实践 / 节点判断）
- **器**：工具系统（益邻平台 / 咿呀水晶 / M515 / AI 智慧体 / 创客星球技术栈）
- **用**：躬身入局验证（徐泾样板 / 益邻家园 / 启愿师经济模型 / 价值回流闭环）

**定位**：共同富裕探路者的**具体可行的宝贵实践经验分享**

**目标读者**：
- 想动手做的实践者（社区运营 / 创客 / 创业者）
- 想用工具放大能力的智慧教练 / 启愿师
- 想躬身入局共建的早期合伙人

## 一·五、双书姊妹架构（7/8 优化版·WHY + HOW）

```
WHY（演绎·从理想到规律）
  └─ A 书 势道法 = 哲科思想求索
     └─ 演绎法 = 从"AI 变革"推导到"分配体系"
     └─ 解决"为什么会变"

HOW（归纳·从实践到共性）
  └─ B 书 术器用 = 最佳实践求索
     └─ 归纳法 = 从"益邻家园等案例"提炼出"术器用共性"
     └─ 解决"具体怎么做"
```

**双书方法论对仗**：
- A = 演绎（理论先行）→ 给读者"方向感"
- B = 归纳（案例先行）→ 给读者"可抄作业"
- **两书互补 = 完整闭环**

## 六、写作约定（沿用 V3 + 增补）

1. **语言**：降维降频，大众能读
2. **第一人称**：严禁捏造，**"我是怎么..."= 抄袭铁律**
3. **东西方金句**：每章配 2-3 句（呼应 B 原书引用系统）
4. **来源标注**：每段末尾标"来源：vault X 档 Y"
5. **章节金句**（V4 增）：**每章用 1 句"势/道/法/术/器/用"作本章定位**
6. **章节收尾**（V4 增）：**每章末尾标"→ 对应 B 书第 X 章 Y 节"**（双书交叉索引）
