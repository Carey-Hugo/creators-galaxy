# T-2026-08-01-002 · aicodewith gpt-image-2 异步调用全流程（#26 实战）

## 关键发现（按重要性排序）

### 1. aicodewith 图像生成 = 异步任务模式（不是 OpenAI 同步返回 URL）
- **POST** `/v1/images/generations` → 返回 `{"id": "task-xxx", "status": "processing", "progress": 5, "task_info": {"estimated_time": 309}}`
- **GET** `/v1/tasks/{task_id}` 轮询 → `{"status": "completed", "progress": 100, "results": ["url"]}`
- **不能用 `response_format=url`** 参数（aicodewith 不支持同步返回）

### 2. access_token 必须在同一脚本内"取+用"原子操作
- 跨脚本调用（先 token 后用脚本）→ 报 40001 invalid credential
- 必须在同一 Python 块里：先 token（time.sleep(1) 等待服务端生效）→ 立即用

### 3. 尺寸必须被 16 整除
- ✅ 1920x832、1536x640、1344x576、1024x448
- ❌ 1919x820（被拒 400 invalid_parameter）
- **像素下限**：pixel budget ≥ 655360（如 1024x448 = 458752 ❌）

### 4. 错误码对照
| 错误码 | 含义 | 处置 |
|--------|------|------|
| 400 model_not_allowed | key 没开通此模型权限 | 改用别的 model（gpt-image-2 替代 -beta）|
| 402 insufficient_quota | credits 用完 | 充值图像 credits（文字对话 quota 不受影响）|
| 4001 invalid_credential | token 失效或跨调用 | 同脚本内取用，加 sleep(1) |

### 5. 中文标题易错字（gpt-image-2 验证）
- "抢饭碗" 可能渲染成 "抢纺碗"/"抢挽碗"
- "黄仁勋" 可能渲染成 "黄人勋"
- **结论**：**AI 不渲染中文标题**——PIL wqy-zenhei 字体叠加（双层描边：金色外 + 深蓝内）更稳
- 底层图可以放心让 AI 渲染（无文字）

### 6. 完整调用模板（验证可用）
```python
import urllib.request, json, time

# Step 1: 提交异步任务
payload = json.dumps({
    "model": "gpt-image-2",
    "prompt": "...",
    "size": "1920x832",
    "n": 1
}).encode("utf-8")
req = urllib.request.Request(
    "https://api.aicodewith.com/v1/images/generations",
    data=payload,
    headers={"Authorization": f"Bearer {api_key}", "Content-Type": "application/json"},
    method="POST"
)
with urllib.request.urlopen(req, timeout=120) as resp:
    task_data = json.loads(resp.read())
task_id = task_data["id"]

# Step 2: 轮询
for i in range(60):
    req = urllib.request.Request(
        f"https://api.aicodewith.com/v1/tasks/{task_id}",
        headers={"Authorization": f"Bearer {api_key}"}
    )
    with urllib.request.urlopen(req, timeout=10) as resp:
        data = json.loads(resp.read())
    if data["status"] == "completed":
        url = data["results"][0]
        break
    time.sleep(10)
```

- 中文字幕易错字
