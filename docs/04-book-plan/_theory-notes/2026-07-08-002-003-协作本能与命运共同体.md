## 一、T-002：挪威维京 vs 中国农耕（足球协作素材）

**核心论证**：
- 海洋（维京/挪威）→ 长船协作 → 平辈自发生态 → 足球 11 人自发同步
- 土地（中国农耕）→ 农夫自守 → 自上而下徭役 → 单人项目沉心苦练
- 关键金句：协作从来不是高尚的道德选择，而是活命的前提

**批判性过滤**：
- 原文"我们并不缺少大规模集结的能力，可普通人平辈之间发自内心的日常配合，长久以来十分稀缺"——准确
- 论证锐度：⚠️ 史实支撑较弱（无具体案例），但论证框架可采

**入书位置**：
- A 书第二章 2.3 节"协作本能的文明缺口"

## 二、T-003：利益共同体 vs 命运共同体（襄阳保卫战素材）

**核心论证**：
- 海洋文明 → 利益共同体 → 顺境优/绝境崩（蒙古西征欧洲骑士团溃散）
- 农耕文明 → 命运共同体 → 顺境松/绝境韧（襄阳保卫战坚守数十年）
- 关键金句：
  1. **以利相聚者，必因利尽而散**
  2. 海洋文明的合作，是为了更好地活着；华夏文明的坚守，是为了文明不绝
  3. 顺境靠合力成事，绝境靠初心立根
  4. 划桨之人，逐利而行，利尽则散；执铧之人，守命而存，脉续则长

**批判性过滤**（胡哥提醒·批判性思维）：

### ⚠️ 3 处需要警惕的表述

1. **"蒙古铁骑横扫欧洲"= 欧亚文明史简化**
   - 原文把欧洲溃散全归因于"无最高权威"
   - 客观史实：13 世纪欧洲是封建采邑制，不是"平级协作"——原文把"骑士团林立"等同于"利益共同体"有些简化
   - 建议：进书时保留论证框架，但加 1 句"高度概括非学术论文"的免责注
   - 处理方案：**框架可采，史实细节需谨慎**（进书时标注）

2. **"我们文明从未孕育出海洋式的自发平级协作"——过于绝对**
   - 反例：晋商票号跨省协作 / 民国商会 / 改革开放温州商帮
   - 这些是少数且非文明主流——所以"从未"是夸张
   - 建议：改"主流"或"主导"，避免学界质疑
   - 处理方案：**改"主流"更稳**

3. **"绝境中无人可以临阵脱逃"——过于浪漫化**
   - 客观史实：南明/崖山/清末/太平天国都有大量临阵脱逃 + 叛变
   - 襄阳保卫战能坚守是少数英雄的坚持，不是"无人可脱逃"
   - 建议：改"少数人选择不脱逃"，避免浪漫化失真
   - 处理方案：**改"少数人"更稳**

## 三、两篇合并的完整论证链

```
【T-002·足球】环境塑造本能层（势）
  └─ 海洋 → 自发协作 / 土地 → 自上而下

【T-003·襄阳】文明在绝境中的分野（势+道）
  └─ 利益共同体（顺境优/绝境崩）
  └─ 命运共同体（顺境松/绝境韧）

两篇合一 → "愿力文明"必须长出**第三种形态**：
  ✅ 顺境有海洋式的自发协作（学维京）
  ✅ 绝境有华夏式的血脉坚守（守文脉）
  = **愿力共同体** = B 书要回答的命题
```

- A 书讲"为什么需要新文明"
- B 书讲"怎么长出愿力共同体"
- 两篇文章正是 B 书底层论证的一半
