# 创客星球（CGHub）小报童产品体系
> 版本：V1.0
> 日期：2026-05-03
> 状态：定稿

---

## 一、完整漏斗

```
【第一层：公众号】免费
→ 战斗檄文，发出声音，吸引同路人
→ 纯传播，不谈钱

【第二层：小报童】9.9元/篇 or 99元/年
→ 99元/年 = 全年内容 + 直接进微信交流群
→ 使命：系统了解这套系统，唤醒梦想，有收获就值了
→ 小报童就是学习知识，订阅费完全值

【第三层：微信群】99元/年
→ 基础种子用户社区
→ 跟着小报童订阅走，续费才能留下
→ 第一个群满了（500人）→ 开始招募飞书群

【第四层：飞书群】399元/年（原价999）
→ 微信群第一群满就开始招募，不等500人
→ 10人满 → 开始共创讨论
→ 初创期优惠399，后期涨至999+
→ 核心共创合伙人：上限100人
→ 有考核/排名/晋升/动态调整，能者上
```

---

## 二、权益进阶机制

**进阶时无需重复购买下层权益，下层全部保留。**

- 进微信群 = 享有小报童全部内容
- 进飞书群 = 享有飞书群+微信群+小报童全部内容

---

## 三、星钻机制

### 3.1 年度窗口（工具上线后开放）

**每年一次，1:1兑换，自愿选择，多买多得：**

| 档次 | 金额 | 获得星钻 |
|------|------|---------|
| 基础档 | 99元 | 99星钻 |
| 标准档 | 399元 | 399星钻 |
| 进阶档 | 699元 | 699星钻 |
| 旗舰档 | 999元 | 999星钻 |

窗口关闭后：只能靠挖矿/创造价值获得星钻，难度翻倍。

### 3.2 游客 vs 付费用户

| 角色 | 可浏览 | 可发言 | 可获星钻 | 享受分红 |
|------|--------|--------|----------|----------|
| 游客 | ✓ | ✓ | ✗ | ✗ |
| 付费用户（任一档次） | ✓ | ✓ | ✓ | ✓ |

### 3.3 星钻特性

- 永久有效，链上记录，不可篡改
- 星钻代表平台"股权"
- 创造的贡献永久被记录

## 五、时间戳权重

- 越早加入，积累越早，权重越高
- 雪中送炭 > 锦上添花
- "因为相信，所以看见"的人值得更多回报
- 后期涨价 = 让先加入的人感觉更值，给后来者紧迫感

---

## 六、飞书群核心100人机制

- 不是淘汰，是让更有能力的人承担更重要的事
- 有考核/排名/晋升/动态调整
- 躺平者调整到非核心，但依然享受平台增值成果
- 100人满了 → 缴费399可进飞书群（非核心），依然享受分红

## 八、年度续费原则

- 所有层级都是年度付费，保障持续现金流
- 不续费 = 失去对应层级权益
- 每年续费 = 持续贡献的证明
- 第二年不续费 → 移出群/失去合伙人资格
