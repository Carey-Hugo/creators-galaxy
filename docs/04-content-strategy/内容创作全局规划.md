## 五、周计划模板（每周执行节奏）

### 5.1 标准周计划

```
周三：公众号文章（主创作，1.5-2小时）
     → 书籍对应章节素材积累

周四：书籍章节写作（1.5-2小时）
     → 为小报童内容打基础

周六：公众号文章 or 小报童文章（早5:55定时发布）
     → 可选第三篇（时间宽裕时）

周一/周二/周五：弹性处理
     → 根据实际情况灵活安排
     → 处理白皮书素材、平台规划等

周日：完全休息
```

### 5.2 内容分配原则

```
每周内容产出：
├── 公众号：2篇（必须）
├── 书籍章节：推进1章的部分内容（积累式）
└── 小报童：按月度计划推进1篇

三线并行，不串行等待。
同一素材，多个出口。
```
