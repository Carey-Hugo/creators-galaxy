## 八、品牌调性执行规范

### 8.1 核心理念

```
【品牌调性：贩卖梦想和希望，不贩卖焦虑】

✓ 我们传递的：
  - AI时代的机会
  - 共同富裕的可能
  - 每个人都能成为创客
  - 参与即确权，创造即价值

✗ 我们不传递的：
  - "再不上车就来不及了"的紧迫焦虑
  - "错过这个机会你就完了"的恐惧营销
  - "别人都成功了你在等什么"的peer pressure
  - 过度渲染"暴富"或"快速成功"
```

### 8.2 文风规范

| 场景 | 文风 | 示例 |
|------|------|------|
| 战斗檄文 | 有力量，有温度，有梦想 | "我们相信，每一个人都能成为创客" |
| 深度长文 | 严谨、有深度、易懂 | "用数据说话，用逻辑说服" |
| 项目介绍 | 专业、清晰、有吸引力 | "6大子项目，总有一个适合你" |
| 行动指南 | 具体、简洁、可操作 | "只需3步，加入我们" |
| 社群互动 | 亲切、共创、正向 | "欢迎分享你的故事" |

### 8.3 禁用词

```
【内容禁用词】
- 绝对化表述：一定、保证、100%等
- 焦虑营销：来不及、错过、后悔等
- 过度承诺：稳赚、暴富、快速成功等
- 攻击性语言：诋毁竞争对手、贬低其他平台
- 虚假数据：未经核实的数字、排名等
```
