# 孔子（Confucius）

## 基本信息
- **时代**: 春秋时期 (公元前551年-公元前479年)
- **著作**: 《论语》、《春秋》
- **核心思想**: 仁、礼、中庸、君子之道

## 经典引用

### 治国理政
1. **"政者，正也。子帅以正，孰敢不正？"**
   - 解释：政治就是端正。领导者以身作则，谁敢不端正？
   - 适用场景：AI治理、平台规则设计

2. **"其身正，不令而行；其身不正，虽令不从。"**
   - 解释：自身端正，不用命令也会执行；自身不端正，即使命令也不服从。
   - 适用场景：领导力、团队协作

3. **"民可使由之，不可使知之。"**
   - 解释：可以让百姓按照规范行事，但不能让他们完全理解背后的道理。
   - 适用场景：用户体验设计、产品简化

### 人际关系
4. **"己所不欲，勿施于人。"**
   - 解释：自己不愿意承受的，不要施加给别人。
   - 适用场景：公平分配、用户权益保护

5. **"君子喻于义，小人喻于利。"**
   - 解释：君子明白的是道义，小人明白的是利益。
   - 适用场景：激励机制设计、价值导向

6. **"三人行，必有我师焉：择其善者而从之，其不善者而改之。"**
   - 解释：三人同行，一定有我可以学习的人：选择好的方面学习，不好的方面改正。
   - 适用场景：团队学习、AI训练

### 教育与学习
7. **"学而不思则罔，思而不学则殆。"**
   - 解释：只学习而不思考会迷惑，只思考而不学习会危险。
   - 适用场景：AI知识融合、深度学习

8. **"知之为知之，不知为不知，是知也。"**
   - 解释：知道就是知道，不知道就是不知道，这才是真正的知道。
   - 适用场景：AI透明性、诚实沟通

9. **"温故而知新，可以为师矣。"**
   - 解释：温习旧知识而得到新理解，可以成为老师。
   - 适用场景：知识传承、迭代优化
