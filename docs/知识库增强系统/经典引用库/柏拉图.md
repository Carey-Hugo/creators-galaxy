# 柏拉图（Plato）

## 基本信息
- **时代**: 古希腊 (公元前428年-公元前348年)
- **著作**: 《理想国》、《苏格拉底的申辩》、《法律篇》
- **核心思想**: 理念世界、灵魂不朽、理想政治

## 经典引用

### 哲学与真理
1. **"未经审视的人生不值得过。"**
   - 解释：没有经过反思和审视的人生是没有价值的。
   - 适用场景：AI伦理审查、产品价值反思

2. **"理念世界比物质世界更真实。"**
   - 解释：理念和形式的世界比物质世界更加真实和永恒。
   - 适用场景：虚拟世界、数字资产价值

3. **"哲学家应该成为国王，或者国王应该成为哲学家。"**
   - 解释：哲学家应该统治国家，或者统治者应该成为哲学家。
   - 适用场景：AI治理、技术领导力

### 知识与教育
4. **"知识就是回忆。"**
   - 解释：真正的知识是对理念世界的回忆，而不是从感官获得的。
   - 适用场景：机器学习、知识发现

5. **"教育的目的是引导灵魂转向真理。"**
   - 解释：教育的真正目的是引导灵魂转向真理和美德。
   - 适用场景：AI教育、知识传播

6. **"洞穴比喻：人们看到的只是影子，而不是真实的事物。"**
   - 解释：人类通常看到的只是现实的影子，而不是真正的现实。
   - 适用场景：数据偏见、算法透明度

### 政治与社会
7. **"理想国应该由哲学家统治。"**
   - 解释：最好的国家应该由有智慧的人统治。
   - 适用场景：DAO治理、专家决策

8. **"正义是灵魂各部分的和谐。"**
   - 解释：正义就是灵魂中理性、激情和欲望三部分的和谐关系。
   - 适用场景：系统平衡、资源分配

9. **"民主制度容易堕落为暴民的统治。"**
   - 解释：民主制度容易演变为多数人的暴政。
   - 适用场景：投票机制设计、共识算法
