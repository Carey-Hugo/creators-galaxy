# 孟子（Mencius）

## 基本信息
- **时代**: 战国时期 (公元前372年-公元前289年)
- **著作**: 《孟子》
- **核心思想**: 性善论、仁政、民贵君轻

## 经典引用

### 人性与道德
1. **"恻隐之心，仁之端也；羞恶之心，义之端也；辞让之心，礼之端也；是非之心，智之端也。"**
   - 解释：同情心是仁的开端，羞耻心是义的开端，谦让心是礼的开端，是非心是智的开端。
   - 适用场景：AI伦理、道德判断系统

2. **"人皆有不忍人之心。"**
   - 解释：每个人都有不忍心看到别人受苦的心。
   - 适用场景：人机交互设计、情感计算

3. **"富贵不能淫，贫贱不能移，威武不能屈，此之谓大丈夫。"**
   - 解释：富贵不能使他放纵，贫贱不能使他改变，武力不能使他屈服，这才叫大丈夫。
   - 适用场景：价值观坚守、抗压能力

### 政治与治理
4. **"民为贵，社稷次之，君为轻。"**
   - 解释：人民最重要，国家其次，君主最轻。
   - 适用场景：用户中心设计、平台治理

5. **"得道者多助，失道者寡助。"**
   - 解释：符合道义的得到很多帮助，违背道义的得到很少帮助。
   - 适用场景：生态系统建设、合作伙伴关系

6. **"仁者无敌。"**
   - 解释：有仁德的人没有敌人。
   - 适用场景：竞争策略、长期主义

### 教育与成长
7. **"天将降大任于是人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为，所以动心忍性，曾益其所不能。"**
   - 解释：天将要把重大任务交给这个人，一定先使他的内心痛苦，使他的筋骨劳累，使他饥饿，使他贫困，使他的行为不顺，以此来震动他的心灵，坚韧他的性格，增加他原来没有的能力。
   - 适用场景：创业精神、逆境成长

8. **"穷则独善其身，达则兼济天下。"**
   - 解释：不得志时就修养好自身，得志时就使天下人都得到好处。
   - 适用场景：个人发展与社会责任

9. **"虽有智慧，不如乘势；虽有镃基，不如待时。"**
   - 解释：虽然有智慧，不如利用形势；虽然有农具，不如等待农时。
   - 适用场景：时机把握、趋势判断
