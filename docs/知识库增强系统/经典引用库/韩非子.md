# 韩非子（Han Feizi）

## 基本信息
- **时代**: 战国末期 (公元前280年-公元前233年)
- **著作**: 《韩非子》
- **核心思想**: 法、术、势结合，君主专制，人性本恶

## 经典引用

### 法与制度
1. **"法不阿贵，绳不挠曲。法之所加，智者弗能辞，勇者弗敢争。"**
   - 解释：法律不偏袒权贵，墨线不迁就弯曲。法律施加到的人，聪明人不能推辞，勇敢人不敢抗争。
   - 适用场景：平台规则、代码即法律（Code is Law）

2. **"明主之道，一法而不求智，固术而不慕信。"**
   - 解释：明君的原则是：统一法制而不依赖个人的智慧，固定权术而不仰慕诚信。
   - 适用场景：DAO治理、自动化系统设计

3. **"刑过不避大臣，赏善不遗匹夫。"**
   - 解释：惩罚罪过不回避大臣，奖赏善行不遗漏平民。
   - 适用场景：公平激励机制、透明治理

### 权术与统治
4. **"事在四方，要在中央；圣人执要，四方来效。"**
   - 解释：事务分散在四方，关键在于中央；圣人掌握关键，四方就会来效力。
   - 适用场景：分布式系统、中心化协调

5. **"不期修古，不法常可。"**
   - 解释：不期望遵循古制，不效法常规。
   - 适用场景：创新思维、打破常规

6. **"是以圣人不期修古，不法常可，论世之事，因为之备。"**
   - 解释：所以圣人不期望遵循古制，不效法常规，研究当代的事情，据此作出准备。
   - 适用场景：适应性策略、与时俱进

### 人性与现实
7. **"夫妻者，非有骨肉之恩也，爱则亲，不爱则疏。"**
   - 解释：夫妻之间，并非有骨肉的恩情，相爱就亲近，不爱就疏远。
   - 适用场景：利益关系分析、激励机制设计

8. **"人主之患在于信人，信人则制于人。"**
   - 解释：君主的祸患在于信任别人，信任别人就会被别人控制。
   - 适用场景：权力制衡、去信任化系统

9. **"明主之所导制其臣者，二柄而已矣。二柄者，刑、德也。"**
   - 解释：明君用来控制臣下的，只是两种权柄罢了。两种权柄就是刑和德。
   - 适用场景：奖惩机制、治理结构
