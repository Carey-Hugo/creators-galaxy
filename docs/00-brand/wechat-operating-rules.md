# 微信公众号推荐运营规范

> 来源：微信官方《公众号和服务号推荐运营规范》
> 生效场景：公众号消息列表-看一看；内容详情页底部推荐；发现页-看一看入口推荐

---

## 一、总则&价值观

**鼓励倡导的内容：**
1. 以传递知识、分享经验和展示个人观点为主要目的，有价值、有深度的原创内容。
2. 提供给用户好的阅读体验、精美的设计和排版的内容。
3. 使读者在轻松阅读中收获知识或思考的具有启发性、教育性或者娱乐性质的内容。
4. 金融、教育、医疗卫生、司法等专业人士发布的权威真实信息和专业知识。

**我们不希望看到的内容：**
1. 违反法律法规、违反社会主义核心价值观的内容。
2. 不实内容：例如通过捏造或扭曲事实的内容以吸引眼球博取流量的内容。
3. 违背公序良俗、违背科学的、不尊重他人的、令人极度不适等不良内容。
4. 仅以营销、广告为目的，缺乏实际价值的宣传和营销推广，甚至虚假宣传的内容。
5. 通过各种手段绕过平台检测、审核的内容。

## 二、运营规范

### 7. 低创作度内容（CGHub 每次创作重点规避对象）

**平台鼓励具有丰富信息含量的内容，欢迎为用户提供信息增量或情绪价值等价值的内容，不鼓励以各种形式进行疑似投机的低创作度内容，包括但不限于：**

#### 7.1 同质化内容
- 短期内，高频发布结构、框架、核心观点完全一致，或多要素高度重合的内容
- 长期复用同一标题/封面图片，或对同一主题/素材反复加工翻炒，导致内容整体重复率过高

#### 7.2 疑似搬运、抄袭等原创度较低的内容
- 疑似搬运内容，大量复述站内、外的内容，仅进行少量语序、标点等轻加工，且不含增量信息
- 通过洗稿重组，保留他人原文核心逻辑/数据，仅重组语序/段落、替换近义词或增减无效信息
- 机械拼接、组合多篇同主题内容，仅作简单拼凑、融合而未提供增量信息的内容

#### 7.3 信息量不足，疑似无法为用户提供有效价值的内容
- 简单拼凑整合无意义信息，堆砌大量形容词、套话，缺乏实质性信息
- 图文失配或看图说话内容，逻辑机械而混乱，形成图、文之间的信息冲突
- 引用疑似不存在的数据、案例、言论作为依据，且未提供可验证来源

#### 7.4 低价值AIGC内容
- 通过AIGC等技术生成文章主体内容，占比显著高于人工创作部分，且并不声明AI辅助创作
- 使用新技术，生成含事实错误、夸大表述或虚构数据的内容
- 简单指令生成套路式/碎片式信息，从而进行大批量发布的低质灌水内容

## 三、CGHub 合规自检清单（每次创作后必查）

| 检查项 | 标准 | 触发条件 |
|---|---|---|
| 同质化 | 核心框架/观点是否为作者原创？有无网络常见鸡汤？ | 结构/框架/核心观点是否与近期文章高度重合 |
| 抄袭洗稿 | 案例是否有独特视角和褒贬分析？ | 是否只做语序重组而无增量信息 |
| 信息量 | 字数≥1500？有无增量洞察？ | 有无"读者能获得什么新认知" |
| AIGC声明 | 是否含有个人真实经历/独特观点，读起来像真人在说话？ | 有无"不仅如此"/"综上所述"等AI过渡词 |
| 导流 | 有无强制/奖励诱导关注？二维码/外链导流？ | 结尾CTA是否合规 |
| 标题党 | 标题是否隐藏关键信息、夸大严重程度？ | 标题与内容是否一致 |

## 四、热点案例事实核查规范（必须执行）

> 自己研究时产生的描述性推断，不能作为可引用的信息来源。

**核查流程：**
1. 每条热点案例必须找到可验证来源（官方发布/权威媒体报道）
2. 中文科技新闻优先用微信搜索/微信公众号内搜索
3. 英文科技新闻用 The Verge / TechCrunch / Wired 搜索
4. 查不到来源的描述性内容→替换为可验证案例，或注明"据公开信息推断"
5. 案例时间标注必须是实际日期，不能人为标注日期

## 五、涉及国家/党政策内容的正面表述规范（品牌安全铁律）

当文章内容涉及人类命运共同体、共同富裕、党的领导等政治性方向时：

- ✅ 正确框架："方向是党指明的，落地是我们一起在做"
- ✅ 正确框架："如同当年马克思主义传入中国，为救国图存提供了思想指引"
- ❌ 禁止负面批评："方向不能落地，就是空话"
- ❌ 禁止暗示领导不作为："怎么来落地？方向已经明确了"

**核心原则：凡涉及国家/党政策方向，必须把"方向"和"落地"表述为正向承接关系——方向在前，我们负责落地。**
