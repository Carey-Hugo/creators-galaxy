## 一、项目全景地图

### 1.1 品牌与定位

| 属性 | 内容 |
|------|------|
| 品牌名 | 创客星球（CGHub）/ Creators Galaxy Hub（CGHub） |
| 旧名 | CreatorsGalaxy / Maker Star（已废弃） |
| 核心公式 | AI（先进生产力）× Web3（生产关系变革）× 共同富裕（理念）= 创客星球 |
| 愿景 | 天下大同、万物共生 |
| 使命 | 创新实践人类命运共同体蓝图，为人类文明的未来形态探路 |
| 定位 | 使命驱动，创客价值操作系统（不是GitHub复制品） |

### 1.2 核心产品三层结构

```
身份层（个人主页/作品集）
    ↓
内容与项目层（内容创作、项目协作）
    ↓
价值记录层（智能合约/链上确权）
```

### 1.3 完整内容漏斗

```
公众号（免费）
    ↓ 战斗檄文，吸引同路人
小报童（99元/年）
    ↓ 深度内容，筛选认同者
微信群（99元/年）
    ↓ 种子用户社区
飞书群（399元/年，原价999）
    ↓ 核心100人，10人开干
```
