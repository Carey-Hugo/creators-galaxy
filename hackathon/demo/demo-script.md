# CGHub 产品演示 Demo 脚本

> **演示时长：** 5-7分钟
> **场景：** Hackathon 路演现场
> **目标：** 让评委和观众在5分钟内理解 CGHub 是什么、解决什么问题、如何使用

---

## 🎬 Demo 总览

**演示主题：**
> "一位独立创客，从加入 CGHub 到完成第一次价值分配的完整旅程"

**所需环境（提前准备）：**
- [ ] CGHub 测试网站（本地或演示服务器）
- [ ] MetaMask 钱包（已装插件）
- [ ] Polygon/Monad 测试代币（Faucet 提前领取）
- [ ] Etherscan 浏览器（查询链上记录）

---

## 📍 场景一：注册与身份（60秒）

**演示者操作：**

```
1. 打开 CGHub 首页
2. 点击"注册" / "Connect Wallet"
3. MetaMask 弹出 → 点击"签名"
4. 页面跳转 → 自动生成创客主页
```

**旁白：**
> "在 CGHub，你不需要注册邮箱、设置密码。只需要一个 Web3 钱包，你就是你自己的身份。
>
> 你的钱包地址，就是你在创客星球的身份证。"

**展示点：**
- 钱包地址作为唯一身份
- 免密登录（Web3 原生体验）
- 自动生成个人主页

---

## 📍 场景二：个人主页与作品集（60秒）

**演示者操作：**

```
1. 进入"我的主页"
2. 上传头像、填写简介
3. 添加作品集：
   - 文章列表（来自公众号）
   - 代码仓库（来自 GitHub）
   - 设计作品（上传图片）
4. 展示"Web3 身份卡"
```

**旁白：**
> "你的主页就是你的数字名片。但这张名片，是你自己拥有的。
>
> 没有人能删除它，没有人能冻结它。
> 你的作品、你的声誉，都锚定在区块链上。"

**展示点：**
- 去中心化身份（抗审查）
- 作品集展示（多类型）
- Web3 声誉系统

---

## 📍 场景三：发起协作项目（90秒）

**演示者操作：**

```
1. 点击"发起项目"
2. 填写项目信息：
   - 名称：CGHub 官网重构
   - 描述：用 Next.js 重构创客星球官网
   - 预算：1000 USDC
3. 设置贡献规则：
   - 前端开发：40%
   - UI设计：30%
   - 内容策划：30%
4. 智能合约预览（显示分配逻辑）
5. 部署合约
```

**旁白：**
> "当你发起一个项目，你同时在部署一个智能合约。
>
> 这个合约里，写清楚了每个人的分成比例。没有人能事后改规则。"

**展示点：**
- 零代码发起项目
- 智能合约自动部署
- 分配规则预先锁定

---

## 📍 场景四：贡献记录与分配（90秒）

**演示者操作：**

```
模拟场景：项目完成，收益分配

1. 进入项目页面
2. 点击"贡献者管理"
3. 添加贡献记录：
   - Alice 完成了首页开发 → 记录
   - Bob 完成了设计稿 → 记录
4. 点击"释放收益"
5. MetaMask 弹出 → 确认签名
6. 展示链上交易记录（TX Hash）
```

**旁白：**
> "每个贡献者的每一笔贡献，都被记录在链上。
>
> 项目完成后，收益按预设规则自动分配。
> 发工资的不是老板，是代码。"

**展示点：**
- 贡献记录透明可查
- 收益分配代码执行
- 无需第三方仲裁

---

## 📍 场景五：Etherscan 验证（60秒）

**演示者操作：**

```
1. 复制合约地址
2. 打开 Etherscan（Polygon 浏览器）
3. 粘贴地址 → 查询
4. 展示：
   - 合约代码（开源）
   - 交易历史
   - 余额变动
5. 展示"Read"标签页的查询功能
```

**旁白：**
> "任何人都可以在区块链浏览器上验证：
> 这个合约开源的，没有人能作弊。"

**展示点：**
- 合约开源（审计透明）
- 链上数据不可篡改
- 无需信任，相信代码

---

## 📍 场景六：AI Agent 辅助（60秒）

**演示者操作：**

```
1. 进入"AI 助手"面板
2. 输入："帮我分析这个项目的贡献记录"
3. AI 返回：
   - 贡献统计
   - 公平性评估
   - 优化建议
4. 输入："帮我生成下个月的创客报告"
5. AI 生成报告（PDF 格式）
```

**旁白：**
> "AI 是你的军师，帮你分析数据、理解规则、优化策略。
>
> 在创客星球，你不是一个人在战斗。"

**展示点：**
- AI 数据分析
- 自然语言查询链上数据
- 自动化报告生成
