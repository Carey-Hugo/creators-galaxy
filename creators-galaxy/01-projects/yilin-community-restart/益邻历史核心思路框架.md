## 〇、一句话定位

**"社区真实社交 O2O 优选线上工具平台 + 社区共享书房线下场景"**

核心模型参照滴滴（共享经济），但社区可共享的资源维度比出行更广（时间/信息/知识/兴趣/技能/活动空间/二手物品），且"同住一个社区"= 天然信任+亲近感 → 社交粘性和驱动力更强。

---

## 一、使命愿景价值观（2019 版）

- **使命**：推动"三全"（全民阅读、全民运动、全面健康），提高全民素养和幸福指数
- **愿景**：共享理念构建和谐、书香、健康、活力、绿色、智慧社区，激发用户主动、实现社区自治，引领社区美好生活方式
- **目标**：
  - 打造社区真实交流、互助共享和精彩内容的线上工具平台（UGC）
  - 构建社区全龄社交活动与消费线下场景（共享书房）
  - 成为未来美好生活主流消费方式的引领者和智慧社区的缔造者
- **价值观**：以邻为伴，诚信友善，互助交往，资源共享，健康快乐，勤学上进，邻里和睦，社区和谐

**"三全"是 2019 版的"价值观锚"——与"愿力文明"的关联点要重新评估（见后续差异分析）。**

---

## 二、目标用户与切入

- **服务用户**：开始聚焦社区**妈妈**，其次为孩子，逐步延伸至社区全龄
- **用户洞察**：
  - 妈妈是家庭的中枢神经和下单的关键节点
  - 成家有娃后妈妈归属感增强，育儿/亲子/社区周边服务需求强
  - 孩子是"高频+长期"消费动力
- **提供内容**：母婴亲子 + 阅读人文类价值观匹配的内容/产品/服务 → 延伸至全龄
- **地域切片**：上海中高端社区起步 → 一二线中高端 → 三四线（融资路线图）

## 三、行业判断（2019 年的市场认知）

| 维度 | 当时判断 |
|---|---|
| 市场规模 | 2020 国内街镇社区服务市场 13.5 万亿；社区商业占社零总额国内 33% vs 发达国家 60%+ |
| 主战场 | 社区 O2O 主导，智慧社区为辅，最终合二为一 |
| 切入阵营 | 物业端（万科住这儿、绿城、彩生活、享家）/ 第三方综合（实惠、小区无忧、58）/ 垂直（闲鱼、拼多多、社区团购） |
| 巨头短板 | 互联网巨头基于地理位置的线下探索是"先天基因决定的"，难以颠覆式创新 |
| 团购赛道 | 烧钱补贴没赢家；微信可随时屏蔽/收编（命运不在自己手里） |
| 社交切入 | "易守难攻，护城河越筑越宽"——腾讯/阿里/小米/新浪 IM 之争为证；叮咚小区（2014 融亿元天使）失败因只攻不守、产品空心化 |

**关键结论**：从社交切入社区，方向正确但产品必须承载实质内容/服务，不能做成"通讯录皮"。

## 四、四大用户痛点（2019 版归纳）

1. **最熟悉的陌生人**：城市化后邻里"无话可说"，但有孩子/老人的家庭迫切需要真实交往
2. **微信群超载**：100+ 群是常态，信息过载，关键信息沉没
3. **身份无法验证**：群里都是网名，不知真实身份/特长/老乡/校友
4. **缺线下场景**：缺面对面的共享空间 + 缺组织者 + 缺可信口碑推荐
5. **物质过剩的悖论**：商品服务多到不会选，需要"可信邻居推荐"背书（点评网/淘宝评论因水军不可信）

## 五、核心解决方案（4 大关键功能）

| # | 功能 | 对应痛点 |
|---|---|---|
| 1 | **邻里真实通讯录** | 网名 → 真实身份 + 籍贯/院校/职业/兴趣/特长/我能提供/期望获得 |
| 2 | **分类发布社区诉求** | 微信群信息过载 → 标签化分类浏览 |
| 3 | **优选可信品质产品服务** | 商品/服务选择困难 + 信任缺失 → 邻居推荐背书 |
| 4 | **线下共享书房 + 社区合伙人激励** | 缺线下场景 + 缺组织者 → 以"阅读+活动"为切入的空间载体 |

## 六、独特的"认证体系"设计（2019 核心创新点）

5 级权限 + 双重认证：
- **注册邻居** → **邻里互认**（需 2 位真实认证邻居 OR 1 真实 + 5 互认推荐，承担连带责任）
- → **真实认证**（身份证 + 房产证/租赁合同，标注有效期）
- → **双重认证**（邻里互认 + 真实认证）
- → 等级标识 + 能量值积分 + 优先排位

**关键洞察**："中国邻里社区的信任必须靠线下链条+连带责任"，这是产品冷启动的关键设计。

## 七、商业模式（产品+用户+推广+盈利）

### 7.1 产品模式
社区真实社交 O2O 优选工具 + 全龄社交生活与消费线下场景

### 7.2 用户模式
- 得用户者得天下
- 妈妈→孩子→全龄
- 70% 股份给合伙人；10% 预留**用户持股**（按虚拟币值兑现，感恩用户价值创造）

### 7.3 推广模式
- 流量池思维 + 裂变三要素（种子/惠及/趣味）
- 存量找增量 + 借高频带动
- 参考 luckin coffee：首杯奖励/拉新奖励/咖啡请客
- 益邻特色：线上任务+虚拟币激励 → 后续可换真金白银 → 重点裂变拉新

### 7.4 盈利模式（4 层）
1. 流量广告（商户竞价排名/点击付费）
2. 优选产品服务的**渠道分销激励**（高频低价+低频高价，吃喝玩乐娱购游+母婴亲子教育医疗文体健旅）
3. 孵化自有价值观产品（高频高价+低频高价，母婴/教育/文体健旅）
4. **会员制**（参考 Costco：买方组织/会员权益/会员费收益）

### 7.5 商业模式补充
- 借鉴茑屋 CCC 的 T-card 积分体系（百万级数据联盟）
- 借鉴云集（赋能开店的人）+ 拼多多（赋能拼团的人）+ 瑞幸

## 八、独特的"社区共享书房"线下模型

### 核心理念
"围绕人群而非想着自己品类"，"货找人" > "人找货"，**千店千面**

### 起步期
- 益邻直营共享书房（社区合伙人运营）
- 图书共享/置换 + 联营新书/CD/DVD/智能电子书
- 茶/咖啡/点心 + 多功能活动空间
- 起步重点牵头读书会/文体艺康养/跳蚤市场

### 扩张期
- 加盟合伙：赋能"有资源有时间想事少离家近开小店"的人
- 凭什么加盟？平台帮你做以用户为中心的策划 + 整合资源落地
- 核心：**数据化运营** → 策划营销执行 → 持续核心竞争力

## 九、三阶段发展路径

| 阶段 | 重心 | 关键动作 | 融资 |
|---|---|---|---|
| **第一阶段 工具层** | 社区真实社交 + 互助共享 + 活动 UGC | 线上工具 + 共享书房小范围验证；不急于变现 | 200 万/出让 10% |
| **第二阶段 街镇周边层** | 产品服务优选 | 物业合作 + 优选商家入驻 + 茑屋 T-card 积分 + 合伙人激励 | 2000 万/出让 5% |
| **第三阶段 区县城市层** | 智慧社区 + 智能家居 | 街道/居委会/物业联合 + 智能硬件投资 | 5 亿/出让 5% |

**T 型战略** = 自有根本性工具平台 + 自主核心价值观产品服务

## 十一、融资计划（2019 版）

- **起步估值**：2000 万
- **资金分配**：99.9 万（实际是首期）→ 核心是 3 人薪资 43.2 万（占比 43%）
- **股权配置**：70% 合伙人 / 20% 财务投资人 / 10% 用户激励
- **退出机制**：隔轮可退出本金让出股份（待完善）
- **关键问题**：早期找"人"难于找"财"，急需财务投资人对社区有共识

## 十二、独特且值得保留的 6 条创始人认知（2019 版）

1. **伟大事业，始于梦想，源于创新，成于实干**——赚钱是顺带的事
2. **城市化 + 流动化 = 重建邻里信任**是时代级机会
3. **得用户者得天下**——必须自建流量池，不依赖微信
4. **做社区要有情怀有灵魂，无情之人做不好社区**
5. **社区创业没有技术门槛，时间就是最大的竞争壁垒**
6. **不盲从权威，不畏惧失败**——拼多多/钉钉都是反巨头打出来的

## 十四、规避/防御策略（2019 版）

- **不跟互联网巨头拼商品力+服务力**（源头直供+物流供应链）——避开阿里的"多快好省"硬刚
- **不依赖微信**（命运在别人手里）
- **不跟物业正面刚**（起步期没有谈判筹码）
- **认证路径**不依赖物业：业主 1 人信任启动社区认证 + 2 人启动前 2 位邻居真实认证 + 信任链复制
- **民主业委会**是潜在"破局点"：让业委会主动拉用户（待论证）
