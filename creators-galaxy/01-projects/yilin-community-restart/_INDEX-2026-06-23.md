## 胡哥新增概念（2026-06-23）
- **核心竞争力=愿力**（不是爱/以人为本）——已有体系+落地系统
- **降维降频** = 让对方听得懂/愿意听
- **启愿师=唤醒者**（胡哥定调）——在档 C 补充层
- **愿力觉醒者** = 初步了解有感觉刚加入的人（招生漏斗前置概念层）
- **AI 时代《新青年》** = 唤醒工具（待展开）—— 发文章？出杂志？建社群？
- **本自具足 ≠ 愿力校真**——前者存在论（本来就有），后者认识论（对齐真相找到）；愿力校真=更准确找到本自具足的愿力
- **虹吸效应**（B+C 混合）= 同频虹吸 + 包容共生虹吸；不是强者恒强是兼容并蓄
- **同频共振 + 吸引力法则**（同频共振语境，非 New Age）= 共识→同频→链接→虹吸
- **筑基期→虹吸期** = 分阶段策略，前期重点连接筑基，后期靠愿力吸引不一个个强拉
- **共识=入口** = 传达不出共识就没法同频链接，吸引力法则就发挥不了
- **信愿才能启愿** = 信→愿→启→行；四层递进（佛学语境非宗教化）
- **共识建军战略转折** = 从项目推动→共识建军；共识是一切的起点
- **快速行动共识** > 思想共识 > 口头共识（关键分类）
- **大道至简哲学观** = 分行/大道相通/借假修真/化繁为简/以道驭术
- **愿力领导力=生命品牌孵化** = 课程+个人 IP 双轨
