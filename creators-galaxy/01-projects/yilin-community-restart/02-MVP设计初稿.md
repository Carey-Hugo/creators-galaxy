## 一、3 个决策固化

### 决策 1：MVP 形态
- **工具栈**：复用 MoWa 明哥的现有 H5 + 微信小程序社区 SAAS 工具
- **定制化范围**：在原有 SAAS 基础上做必要调整（待列需求清单）
- **MVP 内容原则**：**过于庞杂的内容做精简，先把核心主推功能上线**
  - 砍掉：百科/邻里帮/口碑/优选商家入驻/虚拟币交易/动态全分类/通讯录全字段
  - 保留：通讯录骨架 + 1-2 个主推活动 + 1 个交易/闲置 + 1 个认证/愿力记录

### 决策 2：地域起盘
- **第一阶段范围**：**2 个小区**（不是 30 个，不是 1 个）
- **目的**：做出**样板**——让所有人看到信心和希望
- **节奏**：2 个小区跑通 → 复盘 → 扩到 5-10 个 → 再扩到 30+（徐泾复用）

### 决策 3：项目命名
- **正式名**：`益邻 ELINK - 愿力文明美好社区`
- **简称/品牌主名**：`益邻 ELINK`（对内对外传播仍用益邻）
- **精神前缀**：`愿力文明美好社区`（与 MoWa 价值体系对齐）
- **归档**：
  - 2019 历史 BP 仍称"益邻 ELINK"
  - 2026 重启项目全称"益邻 ELINK - 愿力文明美好社区"
  - 未来文章/小程序标题：可简写"益邻·愿力社区"或"益邻愿力社区"

## 二、2 个样板小区选择（待 Hugo 拍板）

### 选项 A：徐泾 30 个小区中挑 2 个
- **优势**：团长网络现成，1 个人能直接激活
- **风险**：旧用户对"团长"角色记忆 = 团购，要重新定义"愿力者"
- **适用条件**：Hugo 愿意亲自在徐泾驻场或高频参与

### 选项 B：全新小区（MoWa 愿力者集中地）
- **优势**：干净环境，愿力者就是第一批种子
- **风险**：要从 0 拉团长/激活
- **适用条件**：MoWa 群里已经有人愿意在自己小区起盘

### 选项 C：混合（1 个徐泾 + 1 个新小区）
- **优势**：A+B 各取所长，对照实验
- **风险**：Hugo 精力分散

我倾向 **C**——1 个徐泾老小区验证"复用团长网络"，1 个新小区验证"愿力者从 0 起盘"。但需要 Hugo 评估精力。

## 三、MVP 主推功能（做精简，只 4 块）

> 原则：所有功能必须回答"愿力文明"或"真实社区连接"或"本地生活"，三选一以上的功能才上。

### 功能 1：邻里真实通讯录（最小可用版）
- **必填字段**：昵称 + 真实姓名（可脱敏）+ 楼栋号 + 入社区时间
- **选填字段**：籍贯/院校/职业/兴趣/我能提供/期望获得
- **认证等级**：简化为 3 级（注册 → 真实认证 → 邻里互认）
- **不做**：复杂权限管理/查看分级/家人关系链
- **解决痛点**："最熟悉的陌生人"

### 功能 2：活动召集（3 类核心活动）
- **3 类固定**：
  1. **读书会**（MoWa 愿力文明相关书 + 社区书）
  2. **跑步/健走**（轻量高频）
  3. **闲置交易市集**（线下 + 线上同步）
- **不做**：复杂分类/票务系统/付费功能
- **MVP 工具**：复用明哥 SAAS 现有的"活动"模块
- **解决痛点**："缺线下场景 + 缺可信内容"

### 功能 3：愿力记录 + 邻里互认（核心创新点）
- **愿力值来源**：
  - 完成邻里互认（被 1 个真实邻居认可 = +X 愿力值）
  - 发起/参与活动（发起 +X，参与 +Y）
  - 闲置交易成功（+Z）
  - 内容被点赞/收藏（+微小值）
- **不做**：通证兑换/股权/交易手续费/打赏
- **MVP 工具**：复用明哥 SAAS "积分"模块 + 自定义字段
- **解决痛点**："AI 时代真实身份 = 真实价值"

### 功能 4：闲置/心愿交易（最小闭环）
- **形式**：邻居发布闲置 / 邻居发布心愿 / 系统按地理位置匹配
- **不做**：商品橱窗/支付闭环/物流跟踪
- **MVP 工具**：复用明哥 SAAS "分类信息"模块 + LBS
- **解决痛点**："物质过剩年代的可信交易"

## 六、风险点 + 应对预案

| 风险 | 严重度 | 应对 |
|---|---|---|
| 明哥 SAAS 工具不够灵活 | 🟡 高 | 退路：先用纯 H5 + 飞书/TG 群跑 MVP，2 周后再切 SAAS |
| 2 个小区主理人招不到 | 🟡 高 | Hugo 亲自做 1 个小区主理人 + 公开招募另 1 个 |
| 真实认证流程太重（要身份证+房产证） | 🟢 中 | MVP 阶段简化为"楼栋号 + 1 个真实邻居互认"即可 |
| 闲置交易触发监管 | 🟢 中 | 限定为"邻里自用 + 非商品化" + 限频次 |
| Hugo 精力分散 | 🔴 高 | 严格限制：本项目每周最多投入 X 小时（待定） |

## 七、衡量 MVP 跑通的标准

跑通即 2 个小区**同时**达到以下 4 条：

1. **真实身份用户 ≥ 50 人/小区**（100 人总量）
2. **完成至少 1 次邻里互认**（证明"信任链"机制可用）
3. **完成至少 3 场活动**（读书会/跑步/闲置市集各 1）
4. **至少 1 个愿力值被多人累计超过 100**（证明"愿力记录"机制可用）

达到上述 4 条 = 样板成立 = 进入徐泾 30 小区复用 + 跨城市复制阶段。
