### 各产品线招生路径

#### P1 启愿师招生
- 漏斗：大众 → 愿力觉醒者 → 启愿师候选 → 启愿师认证
- 入口：精品内容包（P3）
- 转化工具：100 报名 / 36 种子席位
- 配套：发布会 / 共识说明会

#### P2 愿力领导力系统课
- 漏斗：启愿师 → 启愿师认证 → 愿力领导力学生
- 入口：启愿师认证池 + 益邻高净值注册 + 交大校友圈
- 转化工具：试讲打磨 + 首批小班 10-30 人
- 配套：标杆企业家案例（来自档 F）

#### P3 启愿师精品内容包
- 漏斗：公众 → 关注 → 同频 → 转化到 P1 或 P2
- 入口：短视频 / 朋友圈 / 公众号 / 发布会
- 转化工具：四句金句 + 降维降频版启愿师故事
- 配套：发布会 / 共识说明会 / 短视频脚本库

#### P4 KOL 生态无量之网
- 漏斗：网上孤立发声者 → 接触 → 拉入 → 节点共建
- 入口：全网关键词扫描
- 转化工具：愿力文明 OS 话语体系（见面礼）+ 生命花园（线下场）
- 配套：KOL 节点会议
