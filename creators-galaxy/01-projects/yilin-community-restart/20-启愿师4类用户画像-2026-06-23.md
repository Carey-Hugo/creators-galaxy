## 二、详细画像

### 用户 1：成长服务从业者

> **角色定位**：核心种子人群

#### 典型特征
- 已在做"帮人成长"的事（教练/咨询/培训/心理/疗愈）
- 有一定的客户基础
- 寻找更系统的方法论
- 愿意尝试新工具

#### 痛点
- 服务深度受限
- 个体产能天花板
- 缺乏可复制的体系
- 客户复购不稳定

#### 切入点
- **工具赋能**：启愿师方法论作为新工具
- **同行圈子**：和其他成长服务者共学
- **话语升级**：从"教练"升级到"启愿师"
- **价值主张**：能更好地服务自己的客户

#### 转化路径
```
接触 → 试讲 → 同行共学 → 启愿师方法论学习 → 实际应用 → 启愿师认证
```

#### 招生话术
> "你已经会接住人，AI 时代你被重新命名为'启愿师'。愿力文明 OS 让你升级方法论，对接全国同行。"

---

### 用户 2：职场倦怠的转型探索者

> **角色定位**：主力人群

#### 典型特征
- 已在职场 5-15 年
- 出现明显职业倦怠
- 寻求转型但方向不清
- 想做"自己真正想做的事"
- 有一定经济基础（可承受转型期）

#### 痛点
- 不知道自己想做什么
- 不知道如何开始
- 担心转型失败
- 没有支持系统

#### 切入点
- **陪伴式共学**：不是培训，是陪伴
- **自我探索工具**：愿力校真 + 启愿师方法
- **真实案例**：其他转型者的故事（详见档 F）
- **社群支持**：愿力实践社区（详见档 0/K）

#### 转化路径
```
接触 → 启发共鸣 → 愿力觉醒 → 持续陪伴 → 启愿师 / 新方向探索
```

#### 招生话术
> "AI 时代不用再加班，但方向更重要。启愿师不是教你新技能，是帮你找到你本来就有的愿力。"

---

### 用户 3：修行落地的实修者

> **角色定位**：高共识人群

#### 典型特征
- 已有修行/灵性/身心成长背景
- 追求"知行合一"
- 对"心灵鸡汤"反感
- 寻找实修落地路径
- 已有较强愿力觉醒基础

#### 痛点
- 修行和现实工作生活脱节
- 找不到"落地的道场"
- 修行社群缺乏工具支撑
- 找不到"同修又同行"的人

#### 切入点
- **精神共振**：本自具足哲学 → 高度共鸣
- **落地工具**：生命花园 + 愿力实践社区
- **信愿启愿**：与修行路径天然契合（详见档 Q）
- **话语权**：成为 MoWa 体系内的 KOL

#### 转化路径
```
接触 → 精神共振 → 深度共学 → 成为节点 / 燃灯人 → 启愿师 + 修行落地
```

#### 招生话术
> "修行不是远离人间，是把修行带入人间。启愿师是修行的'人间的道场'。"

---

### 用户 4：轻资产创业者

> **角色定位**：增量人群

#### 典型特征
- 已是创业者/自由职业者/数字游民
- 追求轻资产/高杠杆
- 对"流量"和"机会"敏感
- 寻找"新赛道"
- 关注 ROI

#### 痛点
- 业务增长瓶颈
- 单打独斗疲惫
- 寻找新杠杆
- 缺乏使命感

#### 切入点
- **价值证明**：MoWa 价值共生式社交 = 新机会
- **网络杠杆**：KOL 无量之网 = 流量矩阵
- **品牌赋能**：信愿书房 = 统一品牌
- **轻资产模型**：不需要重投入

#### 转化路径
```
接触 → 价值认可 → 试用产品 → 加入社群 → 共建生态 → 启愿师 / 投资人
```

#### 招生话术
> "AI + 区块链双螺旋已经形成新赛道。启愿师不是新职业，是新文明的基础设施。轻资产，高杠杆，势不可挡。"

## 三、4 类用户的优先级与策略

### 优先级排序（建议）

| 优先级 | 用户类别 | 理由 |
|--------|---------|------|
| 🔴 最高 | **修行落地的实修者** | 已有信愿基础，最快进入，最易成为节点 |
| 🔴 高 | **成长服务从业者** | 同行影响力大，能批量转化为启愿师 |
| 🟡 中 | **职场倦怠转型者** | 主力人群但转化周期长，需陪伴 |
| 🟢 增量 | **轻资产创业者** | 看 ROI 决策，决策快但忠诚度需培养 |

### 招生漏斗（基于 4 类用户）

```
修行实修者 ┐
           ├→ 快速入口（已信愿）→ 燃灯人/节点
成长服务者 ┘

倦怠转型者 ─→ 陪伴式共学（2-3 月）→ 愿力觉醒 → 启愿师

轻资产创业 ┐
           ├→ 价值证明驱动 → 试用 → 共建生态
新赛道关注 ┘
```
