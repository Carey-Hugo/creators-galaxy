> 目的：把 Hugo "用户贡献持股 50% 锁死"的想法落到 3 步可执行路径

---

## 〇、核心原则（5 条）

1. **"50% 给用户" = 用户经济权益池占 50%（不可稀释），不是工商登记持股 50%**
2. **决策权 = 初创团队（一致行动人），用户通过用户代表大会参与重大事项**
3. **3 步走** = MVP 期用 Token 模拟 → 用户量起来后用有限合伙 → 规模化前做正式架构
4. **核心驱动 = "初创团队代表全体用户"的法定义务**（写进章程 + 用户代表大会决议机制）
5. **所有文件须经专业律师审核后才能落地**——本方案为框架性草案

---

## 一、第 1 步（MVP 期，0-12 月）：Token 模拟 + 工商 100% 创始团队

### 1.1 工商登记层面
- **公司 100% 由初创团队持股**
  - 创始人（CEO）40%
  - 联合创始人（CMO/CTO/COO 视情况）30%
  - 员工期权池 20%
  - 创始人代持的"用户激励预留股"10%（这部分在第 2 步转入合伙企业）
- **重大事项**：股东会决议，**用户无法律投票权**

### 1.2 用户经济权益（核心创新）
- **载体**：星钻 / 愿力值（区块链上链或中心化数据库，二选一）
- **总量规则**：
  - 总星钻池 = 公司总估值 × 50% / 单位星钻价值（**用户经济权益池 50% 锁死**）
  - 星钻**不可增发**（除公司新轮融资等比例扩容）
  - 星钻**不可转让/不可交易/不可套现**（除公司主动回购销毁）
- **分配规则**：
  - 用户按**愿力值/贡献度**动态获取星钻
  - 每月公示"星钻榜"和"星钻价值估算"
- **经济权益**：
  - **估值增值**（按比例享受公司估值上抬）
  - **现金分红**（公司盈利后，按星钻占比分红，每年 1 次）
- **治理权益**：
  - 用户**无日常决策权**
  - 用户通过**用户代表大会**对"用户经济权益池的规则变更"有否决权

### 1.3 法律文件清单（MVP 期必备）
- [ ] 公司章程（含 50% 经济权益池原则）
- [ ] 用户服务协议（明确星钻规则）
- [ ] 星钻规则说明（白皮书形式）
- [ ] 用户代表大会章程（治理机制）
- [ ] 创始团队一致行动人协议
- [ ] 用户激励预留股代持协议

### 1.4 关键风险
- **Token 在国内的合规性**：2026 环境下，星钻如果是"权益型 Token"仍敏感
- **应对**：MVP 期内**不上链**（中心化数据库），不叫"Token"叫"星钻"，避开监管红线
- **等用户量大+融资前**再评估是否上链（链上可证明不可篡改，对融资有加分）

## 二、第 2 步（用户量起来 / 融资前，6-18 月）：有限合伙架构

### 2.1 触发条件
- 用户数 ≥ 1000 真实认证
- 启动 A 轮融资
- 律师正式介入

### 2.2 工商登记层面
- **公司股权重做**：
  - 初创团队直接持股 → **降至 30%-40%**
  - 员工期权池 10-15%
  - 财务投资人占 15-25%
  - **用户持股合伙企业** 持公司 30-40%
- **用户持股合伙企业**结构：
  - **GP（普通合伙人）= 初创团队**（执行合伙事务，掌握决策权）
  - **LP（有限合伙人）= 全体用户**（按星钻占比，享受经济权益）
  - GP 持有 1% 合伙份额，LP 持有 99% 合伙份额
  - 合伙企业**不可解散**（除非公司解散）

### 2.3 治理结构
- **股东会**：
  - 初创团队 + 财务投资人 + 用户合伙企业三方
  - 重大事项按持股比例投票
- **用户代表大会**：
  - 由星钻榜前 N 名 + 街道镇合伙人推选组成
  - 对"用户经济权益池规则变更"有一票否决
  - 每年至少 1 次，可临时召开
- **董事会**：
  - 初创团队 2 席
  - 财务投资人 1 席
  - 用户代表大会推选 1 席
  - 独立董事 1 席

### 2.4 法律文件清单
- [ ] 有限合伙协议（用户持股合伙企业）
- [ ] LP 协议（每个用户签）
- [ ] 用户代表大会章程（升级版）
- [ ] 股东协议
- [ ] 章程修正案
- [ ] 财务投资人投资协议（含一票否决权范围限定）

### 2.5 关键风险
- **用户 LP 进出的灵活性**：用户注册/退出频繁，合伙企业 LP 名册更新成本高
  - **应对**：用"虚拟 LP"模式——用户只持有合伙企业的"虚拟份额"，实际登记在 GP 名下，按合约代为行使 LP 权益
- **用户合伙企业不可解散**：要写进章程
- **GP 道德风险**：GP 既是初创团队又是 GP，可能"自己管自己"
  - **应对**：用户代表大会对 GP 行为有监督权，重大事项一票否决

## 三、第 3 步（远期，规模化 / 上市前）：三方治理

### 3.1 触发条件
- 启动 B 轮/C 轮融资
- 公司估值 ≥ 10 亿
- 准备 IPO 或被并购

### 3.2 工商登记层面
- **公司股权重构**：
  - 初创团队直接持股 15-20%
  - 员工期权池 10%
  - 财务投资人 25-30%
  - **用户持股合伙企业** 持 30-40%（**用户经济权益池 50% 锁死原则的最终落地**）
  - 战略投资人 5-10%

### 3.3 治理结构
- **股东会** = 三方（初创团队 / 财务+战略投资人 / 用户合伙企业）
- **董事会** = 5-7 席
  - 初创团队 2 席
  - 投资人 2 席
  - 用户代表大会 1 席
  - 独立董事 2 席
- **用户代表大会** = 升级为"用户治理委员会"，常设机构
  - 设主任委员 1 名（用户代表大会选举）
  - 对公司重大事项有咨询权 + 部分事项一票否决权
- **监事会** = 必设

### 3.4 关键升级
- **链上星钻**：上链记录所有星钻分配，不可篡改
- **用户数据治理**：用户数据所有权归用户，使用权归公司（参考 GDPR）
- **退出机制**：IPO 时用户可选择星钻换股或换现金

### 3.5 关键风险
- **用户持股 50% 锁死 vs IPO 公众持股 ≥ 25% 的冲突**
  - **应对**：用户合伙企业持股 30-40% 即可（IPO 后会被稀释到 20-25%）
- **用户代表大会治理成本**：随用户规模扩大治理难度指数级上升
  - **应对**：分层治理（小区/街道镇/城市/全国 四级代表）

## 四、关键机制设计（贯穿 3 步）

### 4.1 "用户经济权益池 50% 锁死"的实现
- **定义** = 公司总估值 × 50% 对应的星钻总池
- **写入章程** = "未经用户代表大会三分之二同意，不得变更星钻总池占公司估值的比例"
- **触发条件** = 新轮融资时等比例扩容（财务投资人投 1 元，星钻池同步 +0.5 元价值的星钻）
- **极端情况** = 公司被并购时，星钻池按最后估值兑现给用户（写进章程）

### 4.2 "初创团队代表全体用户"的法定义务
- **GP 职责条款**（有限合伙协议中）：
  - GP 必须以"最大化用户长期利益"为首要原则
  - 重大决策前需咨询用户代表大会
  - 用户代表大会可发起"GP 罢免动议"（需 2/3 用户代表同意）
- **道德承诺写进章程**：让"代表用户利益"从道义变成法律义务

### 4.3 星钻价值估算方法
- **方法 A**（简单）：星钻总价值 = 公司估值 × 50% / 总星钻数
- **方法 B**（精确）：每个星钻 = （公司净现金流 × 50% / 总星钻数） + （公司估值 × 50% / 总星钻数 / 风险系数）
- **MVP 期用方法 A**，规模化后用方法 B

### 4.4 用户代表大会的"分级治理"
- **小区级**：小区合伙人 + 居民代表
- **街道镇级**：街道镇合伙人 + 小区代表
- **城市级**：城市合伙人 + 街道镇代表
- **全国级**：城市合伙人 + 用户代表大会常委会
- **各级代表任期 2 年**，可连选连任 1 次

## 六、待专业律师确认的 12 个核心问题

1. "用户经济权益池 50% 锁死"在《公司法》层面如何落地？章程条款 + 股东协议 + 有限合伙协议 三层结构可行吗？
2. 星钻/愿力值作为经济权益载体的国内合规性（不叫 Token 能否规避？）
3. 用户作为 LP 进有限合伙的可行性（用户实名认证 + 合伙企业份额代持组合是否可行？）
4. GP 罢免机制的法律实操性（用户代表大会发起罢免动议是否需要法律授权？）
5. 公司被并购时星钻池强制兑现条款的合法性
6. 用户代表大会的法律地位（非法人组织？社会团体？章程治理？）
7. 一致行动人协议的具体条款
8. 创始团队代持"用户激励预留股"10% 的合法性
9. 用户数据归属条款（用户 vs 公司）
10. 公司跨境架构（如未来海外业务）是否需要 VIE
11. 财务投资人的"一票否决权"范围限定（不参与日常决策的具体边界）
12. 工会/职代会与用户代表大会的关系（避免双重治理冲突）

## 七、参考案例

- **消费者合作社**（如美国 REI、日本生活俱乐部）：用户作为会员持股 + 治理
- **合作社型企业**（Cooperative）：国际通行做法
- **海尔人单合一**：员工 + 用户共治
- **Patreon / Substack**：创作者经济平台的内容贡献者分成
- **Web3 DAO**：链上治理 + 经济权益分配（如 Uniswap、Gitcoin）
- **传统股份合作制企业**：国内有法律基础（《农民专业合作社法》）

## 八、3 条风险预警（必须记住）

### 风险 1：50% 锁死 vs 后续融资稀释
- **问题**：公司 A 轮/B 轮融资，新投资人进来，老股东被稀释
- **后果**：用户合伙企业占股可能从 30% 降到 15%（如果只按股权计算）
- **应对**：章程写"用户经济权益池按估值比例计算，不按股权比例计算"——即"无论工商登记多少股，用户的 50% 经济权益不变"

### 风险 2：用户代表的"代理人风险"
- **问题**：用户代表大会被少数人控制
- **后果**：与"代表全体用户"原则背离
- **应对**：任期制 + 轮换制 + 罢免机制 + 公开议事规则

### 风险 3：公司长期不盈利
- **问题**：公司烧钱期长，分红少
- **后果**：用户星钻"看得见摸不着"，激励失效
- **应对**：MVP 期星钻不只对应"现金分红"，还对应"会员权益/服务优先权/治理投票权"等"软权益"
