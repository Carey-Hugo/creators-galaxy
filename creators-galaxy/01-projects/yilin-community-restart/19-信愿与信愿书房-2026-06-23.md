## 一、哲学基础：信愿才能启愿

> 来源：胡哥 2026-06-23 战略主张（融合佛学语境）

### 核心命题
**信愿才能启愿，才有愿力行动。**

含义：
- **信**：对愿力文明的信心/信任/信念（认知层）
- **愿**：发愿/立愿/承诺（意愿层）
- **启**：启愿/被唤醒/被接引（触发层）
- **行**：愿力行动（落地层）

四者递进，缺一不可。

### 与佛教"信愿行"的关系

| 佛教 | MoWa 体系 | 含义 |
|------|----------|------|
| 信（信心）| 信 | 相信愿力文明是真的 |
| 愿（愿力）| 愿 | 愿力觉醒 + 立下承诺 |
| 行（修行）| 启 + 行 | 启愿 → 行动 |

### 三层逻辑

#### 第一层：无信则无愿
一个人如果不相信愿力文明是真的，他不会发愿。
- 没有信任就没有承诺
- 没有承诺就没有行动

#### 第二层：有信有愿才能启
信+愿 = 心门打开
心门打开 = 启愿师能接引
启愿师能接引 = 本自具足被看见

#### 第三层：启愿才有愿力行动
被启愿 ≠ 自动行动
- 启愿师提供"被看见"的契机
- 个人需要"愿意行动"的内在驱动
- 内在驱动 = 愿力

### 与档 J（本自具足）的关系
- 档 J 哲学层：本自具足（本来就有的）
- 本档哲学层：信愿（先相信 + 立愿才能被启）
- **两者构成完整的"觉醒来临"路径**：
  ```
  本自具足（事实层：本来就有的）
    ↓
  信（认知层：愿意相信）
    ↓
  愿（意愿层：愿意承诺）
    ↓
  启（触发层：被唤醒）
    ↓
  行（行动层：愿力行动）
  ```

## 四、对招生漏斗的影响

### 旧漏斗（基于档 E 招生手册）
```
大众 → 关注者 → 同频者 → 愿力觉醒者 → 启愿师
```

### 新漏斗（加入信愿环节）
```
大众 → 关注者 → 同频者
   ↓
   信（愿意相信愿力文明是真的）
   ↓
   愿（愿意立愿承诺）
   ↓
   启（被启愿师唤醒）
   ↓
   愿力觉醒者 → 启愿师
```

### 漏斗关键变化
- **新增"信愿"环节**：在同频 → 觉醒之间
- **新增"愿意相信"门槛**：不是所有同频者都能进入
- **新增"愿意承诺"门槛**：信之后必须立愿

## 五、对 4 类启愿师用户的影响

> 详见 → [[20-启愿师4类用户画像-2026-06-23]]（档 T）

### 信愿门槛对 4 类用户的不同影响

| 类别 | 信门槛 | 愿门槛 | 综合 |
|------|--------|--------|------|
| 成长服务从业者 | 低（已有方法论倾向）| 中 | 易进入 |
| 职场倦怠转型者 | 中（半信半疑）| 中 | 需要深度共学 |
| 修行实修者 | **低**（已经有信仰倾向）| 低 | **最快进入** |
| 轻资产创业者 | 中（看 ROI）| 中 | 看具体价值主张 |

### 招生策略调整
- **修行实修者** = 最快入口（已信愿）
- **成长服务从业者** = 工具/方法论先行
- **职场倦怠转型者** = 陪伴式共学
- **轻资产创业者** = 价值证明 + 案例驱动
