**作者 / 组长**：胡哥（Carey Hugo）·媒体宣传组
**来源主导**：以明哥 2026-07-10 三份源头档 + 第二次筹备会纪要 + 档 25 共识底座 + 档 26 邀约沟通 + 档 28 信息矩阵 V0.1 为统一话语基础。

**使用边界**：

- 联系人字段：标"待确认"的必须由对应小组在 7/24 前补齐。

## 一、渠道分层逻辑

### 1.1 四层结构

```
┌─────────────────────────────────────┐
│  第 1 层：自有渠道（主阵地）          │  0 成本，高频
├─────────────────────────────────────┤
│  第 2 层：核心共建者个人渠道          │  0 成本，信任高
├─────────────────────────────────────┤
│  第 3 层：合作传播渠道                │  0 成本/资源互换
├─────────────────────────────────────┤
│  第 4 层：付费/广告渠道               │  留口子，按需启用
└─────────────────────────────────────┘
```

### 1.2 渠道分级原则

| 优先级 | 含义 | 启用条件 |
|---|---|---|
| **P0** | 会前会中会后**必发**的主阵地 | 7/25 起按内容日历执行 |
| **P1** | 会前会中**应当发**的扩展阵地 | 8/5 前完成搭建，8/5 起按节奏发 |
| **P2** | 8/10 之后**按需补**的放大阵地 | 主阵地稳定后补 |
| **待定** | 等嘉宾/场地/议程定盘后确认 | 7/24 后回写 |

### 1.3 渠道字段说明

每条渠道标注 8 个字段：
1. **渠道名**（具体账号/平台/媒体名）
2. **层级**（1=自有 / 2=共建者 / 3=合作 / 4=付费）
3. **联系人**（主理人/编辑/负责人）
4. **受众匹配**（对应档 28 7 类受众哪一类）
5. **内容适配**（短文/长文/视频/海报/直播哪种）
6. **预期触达**（粉丝量/阅读量级）
7. **优先级**（P0/P1/P2/待定）
8. **状态**（✅已确认 / 🟡搭建中 / ⏸待定）
